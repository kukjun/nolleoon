## 다음 기록
[새 버전 템플릿](TEMPLATE.md)을 복사해 **새 KST 날짜 디렉터리**를 만든다. 기존 PNG·manifest·설명을 덮어쓰지 않는다. 승인/거절/정정도 별도 새 기록에서 이전 버전을 참조한다. 최신 링크와 이력 표만 새 버전으로 갱신한다.

1. 같은 합성 상태/viewport/폰트/아바타 로딩 조건으로 실제 위젯과 웹을 렌더한다. 다른 조건이면 숨기지 말고 명시한다.
2. 원본 PNG를 편집하지 않고 복사하며 SHA-256·파일 개수·크기를 대조한다. 원본 mtime은 기록 당시 timezone과 함께 manifest에 고정한다.
3. 실제 사용자·토큰·연락처·비공개 사진이 없음을 확인한다. 폰트 바이너리나 개인 경로는 커밋하지 않는다.
4. 화면별 읽기 순서, 주요 CTA, 뒤로가기/취소/결과→로비, 메뉴 위치, 크림·녹색·파랑 색감을 비교하고 남은 차이를 기록한다.
5. 기능 회귀 결과와 시각 승인 결과를 별도로 적는다. 캡처만으로 API·실기기·접근성 합격을 표시하지 않는다.
6. 사용자가 명시 승인한 버전만 새 승인 기록에 승인 근거를 남긴다. 자동 diff 통과를 디자인 승인으로 바꾸지 않는다.
