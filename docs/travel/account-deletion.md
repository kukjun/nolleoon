# 계정 탈퇴와 참여 판 최소 집계

사용자 승인 범위: 탈퇴 계정이 참여한 판의 모든 작성자 자유 입력을 지우고 숫자 집계와 종료 상태만 남긴다. 영속 여행방은 자동 만료하지 않는다. 관리자 이양/마지막 관리자/활성 판 예외는 승인된 것으로 간주하지 않고 차단한다.

- `POST /api/account/delete`는 현재 계정 쿠키, 기존 Origin/CSRF 검사와 `{requestId, confirmation:'계정 탈퇴'}`를 요구한다. 다른 accountId 입력은 받지 않는다.
- 외부 삭제 원장에 최소 opaque 계정/판/명시 연결 legacy proof를 동기 fsync한 뒤 동일 SQL transaction에서 지운다. 원장 미설정은 503이며 앱이 자동으로 빈 원장을 만들지 않는다. 설정된 원장의 pending 삭제는 시작 시와 매 API 요청 전에 재적용한다. 적용 불능은 일반 조회도 503으로 차단한다.
- provider identity, 앱 로그인 세션/OAuth 시도, 앱 프로필 사진을 제거하고 FK용 계정 행은 비활성 비식별 tombstone으로 남긴다. 삭제 응답 재전송용 세션 **해시**와 만료시각은 인증 권한 없는 최소 영수증이다. 원시 토큰은 저장하지 않는다. 동일 요청은 재삭제/재실행하지 않는다.
- 참여 travel 판의 settings/state/result 자유 입력과 타 작성자 영수증 속 복사본까지 제거한다. requestId 영수증은 `redacted`로 유지하여 과거 요청이 새 명령으로 다시 실행되지 않게 한다. 외부 DTO는 `redacted:true`와 숫자 summary만 포함한다. 이름/참가자 목록/진행자/배정/메뉴 이름/사건/벌칙/변론/이유는 공개하지 않는다.
- 남은 재판 참가자 권한은 현재 소속 + 기존 참가자 증거로 제한한다. 타인의 최소 내부 권한 증거는 보존하지만 탈퇴자의 참가 증거와 현재 소속은 정리한다. 관리자 권한으로 재판 열람권을 넓히지 않는다.
- legacy는 명시적으로 계정 연결된 판만 대상으로 한다. 같은 익명 세션의 다른 판 소유권은 추정하지 않는다. 다른 판과 공유되는 원래 익명 방 멤버 행을 일괄 삭제하거나 닉네임을 바꾸지 않는다. redacted projector는 해당 행을 표시하지 않는다.
- 백업 복원에서는 검증된 원장을 새 비공개 복원본에 재적용한다. 삭제 시점보다 오래된 진행 판은 명시 restore 옵션으로 중단한다. 집계는 백업 시점 자료이므로 유실된 최신 최종 결과를 복구했다는 뜻은 아니다.

## 별도 출시 게이트
실제 카카오 서비스 연결 해제 API는 아직 구현/검증하지 않았다. 로컬 provider 연결 제거를 카카오 측 연결 해제 완료로 표시해서는 안 된다. 운영 원장 초기화/경로 설정/실제 계정 삭제/운영 백업 삭제는 이 개발 작업에서 실행하지 않았다. 실제 데이터 영구삭제는 별도 확인 대상이다.
