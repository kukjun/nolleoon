# 계정 탈퇴 중 게임과 마지막 관리자 정책

2026-11-18 사용자 추가 승인에 따른 변경이다. 앞선 설계의 진행 중 게임 및 모든 관리자 탈퇴 차단은 아래 범위에서 대체한다.

- 현재 멤버가 본인 한 명인 여행방 관리자는 탈퇴할 수 있다. 방은 기존 7일 삭제 대기로 들어가며 자동으로 다른 관리자나 계정을 만들지 않는다.
- 다른 현재 멤버가 있는 방의 관리자는 여전히 이양해야 한다. 임의 위임은 하지 않는다.
- 진행 중 판의 동결 참가자 또는 작성 진행자가 탈퇴하면 해당 판을 중단한다. 현재 초안의 작성자 또는 선택 참가자도 해당한다. 단순 방 멤버이지만 해당 판에 미참가/미선택이면 판을 건드리지 않는다.
- 이미 끝난 타인 작성 초안에 선택만 되었던 경우는 이전 보존 범위대로 유지한다.
- 관련 판의 모든 작성자 자유글과 신원 결합 결과를 제거하고 숫자만 남긴다. 제비는 이미 공개한 수만 집계하며 미공개 배정은 폐기한다. 현재 투표의 미공개 표/이유는 결과로 공개하지 않는다.
- 기존 남은 참가자의 내부 접근 증명은 유지하되 외부 숫자 DTO에 포함하지 않는다. 재판 접근 제한도 확대하지 않는다.

## 원자성 및 복구

계정 삭제 원장 한 항목에 선택적 `roomDeletions`를 기록한다. 기존 항목의 바이트/해시 및 필수 필드는 바꾸지 않는다. 새 필드는 정확한 방/시각/버전/관리자 범위만 담고, 원장 fsync 후 방 tombstone과 계정 삭제를 같은 SQL 트랜잭션에서 적용한다. SQL 실패 후 ordinary request는 재적용 실패 시 503으로 차단한다. 원장 재생은 같은 삭제 시각과 7일 기한을 유지한다.

복원은 승인된 외부 최신 원장을 적용해야 한다. 새 계정을 생성하거나 삭제된 신원을 되살리지 않는다. 운영 DB·파일·실제 계정은 이 개발 과정에서 변경하지 않는다. 외부 Kakao 연결 끊기와 실제 배포 검증은 별도 출시 조건이다.
