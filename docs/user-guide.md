# 놀러온 사용 안내

현재 서비스 주소: https://nolleoon.kukjun.com

2026-11-18 인계 기준 운영은 `d69867be50696dde8a56c532f07412d01221e73a`이며 PR #145의 계정·영속 여행방 개편은 별도 미배포 범위다. 아래 본문은 **기존 브라우저 신원의 재판 흐름**을 설명한다. 운영의 팀 나누기·제비뽑기는 게임 선택 화면에서 선택하며, 아래 피고·벌칙 동의 규칙을 다른 게임에 적용하지 않는다. 여행방 개발 규칙은 [별도 문서](design/travel-current-rules.md)를 참고한다.

이전 도메인의 쿠키·localStorage는 새 도메인으로 자동 이전되지 않는다. 같은 닉네임이나 같은 기기라는 이유로 이전 익명 기록이 복구되지 않는다. [주소 변경·신원 안내](branding.md)를 확인한다. 새 주소나 문서가 실제 카카오 로그인, 실기기 인수 완료를 뜻하지는 않는다.

## 1. 방 만들기와 참여

1. `이 브라우저로 시작`을 누른다. 계정 대신 이 브라우저의 쿠키로 신원을 구분한다.
2. 닉네임을 입력하고 `방 만들기`를 누른다. 방을 만든 사람이 첫 방장이다.
3. `초대 링크 복사`로 친구에게 링크를 전달한다. 친구는 링크에서 브라우저 신원을 만들고 닉네임을 입력해 참여한다. 같은 방에서 중복 닉네임은 사용할 수 없다.

방 조회가 늦어지면 `방 연결 다시 확인`을 누른다. 생성·참여 응답을 못 받았더라도 서버에서는 처리됐을 수 있다. 자동 재전송은 없고 닉네임은 유지한다. 참여는 같은 링크에서 다시 시도할 수 있지만, 방 만들기를 다시 누르면 새 방이 생길 수 있다. [진입 오류 안내](entry-recovery.md)

## 2. 역할·설정·벌칙 수락

- 각자 `참가자` 또는 `피고`를 선택한다. 피고는 한 명이다. 방장도 피고가 될 수 있다. 원고 역할은 없다.
- 방장은 사건·벌칙·시간을 작성하고 `설정 저장`을 누른다. 기본 시간은 3분이며 1~10분으로 바꿀 수 있다. 저장하지 않은 입력은 다른 사람에게 적용되지 않는다.
- 피고는 **서버에 저장된 벌칙**을 확인한 뒤 동의하거나 거절한다. 벌칙이나 피고가 바뀌면 다시 확인해야 한다.
- 시작 조건이 충족되지 않으면 화면에 부족한 조건이 표시된다. 접속 중인 참가자가 방장과 피고를 포함해 최소 3명이고 최신 벌칙에 동의해야 방장이 `재판 시작`을 누를 수 있다.

## 3. 변론과 투표

재판 시작 때 역할과 투표자 명단을 고정한다. 피고는 투표하지 않는다. 늦게 참여한 사람은 관전하며 해당 판의 투표권은 얻지 않는다.

피고는 변론을 작성하거나 건너뛸 수 있다. 변론은 선택 사항이며 별도 타이머가 없다. 방장은 피고 응답이 없어도 투표를 시작할 수 있다. 투표 시간을 바꿨다면 먼저 저장해야 한다. 1차 투표를 시작한 뒤에는 시간을 바꿀 수 없다.

방장이 `다 같이 투표 시작`을 누르면 모두 같은 마감으로 투표한다. `유죄`·`무죄`는 이유가 필수이고 `기권` 이유는 선택이다. 서버가 접수한 표는 바꾸거나 철회할 수 없다. 응답이 유실되어 재확인이 필요하면 화면의 동일 요청 재시도를 따른다. 재시도는 새 표를 추가하지 않는다.

남은 시간이 0이어도 기기 화면이 판결을 임의로 만들지는 않는다. 서버 정산 결과를 기다린다. 전원이 제출하면 즉시 정산하며, 마감 때 미제출은 기권으로 처리한다.

## 4. 결과와 재투표

- 유죄표가 무죄표보다 많으면 유죄, 반대면 무죄다. 기권은 유죄·무죄 비교에서 제외한다.
- 모두 기권이면 무판결이다.
- 1차에서 유죄·무죄가 같은 양수이면 1차 표수와 익명 이유를 공개한다. 피고의 선택적 최후 변론 뒤 방장이 2차 투표를 시작한다. 투표자 명단과 시간은 1차와 같다.
- 2차에서도 유죄·무죄가 같은 양수이면 무죄로 마무리한다. 2차 전원 기권은 무판결이다.

완료된 라운드의 익명 이유는 볼 수 있지만 진행 중인 라운드의 다른 사람 표와 이유는 볼 수 없다. 이름은 숨겨도 표현이나 소수 인원 때문에 작성자를 추측할 수 있다. 유죄일 때만 수행할 벌칙을 안내하며 실제 수행 여부를 관리하지 않는다.

## 5. 같은 방에서 다음 게임

결과 또는 중단 뒤 방장은 다음 게임 준비를 확인할 수 있다. 방과 참가자는 유지하고, 사건·벌칙·피고·수락·표는 새로 정한다. 시간은 다시 3분이다. 이전 판은 별도 기록에서 확인하며 새 게임 화면에 섞이지 않는다.

## 6. 내 게임 기록과 브라우저 신원

`내 게임 기록`에서 **이 브라우저 신원으로 참여한 게임**을 확인한다. 진행 중 기록은 진행 상태와 사건만, 완료된 기록은 결과와 공개된 이유를 보여준다. 게임이 끝난 뒤 링크로 들어왔다고 과거 기록에 접근할 수는 없다.

신원은 마지막 발급·갱신부터 90일간 유지된다. 쿠키 삭제·만료 또는 다른 브라우저/기기에서는 같은 닉네임으로 복구할 수 없다. 신원을 잃으면 이전 비공개 화면을 숨기고 명시적으로 새로 시작하도록 안내한다. 서버 기록의 초기 자동 삭제 기한은 없지만 영구 보관을 보장하지 않는다.

## 7. 연결 끊김·나가기·방 닫기

연결이 끊겨도 바로 퇴장하지 않는다. 같은 브라우저로 돌아오면 최신 상태를 다시 확인한다. 서버가 끊김을 감지한 뒤 10분 안에 돌아오지 않으면 나간 것으로 처리한다. 투표 마감은 늘어나지 않는다.

`방 나가기`를 확인하면 즉시 참여가 종료된다. 다시 참여해도 이미 진행 중인 게임의 투표권이 부활하지 않는다. 방장이 나가면 접속 중인 다른 참가자에게 무작위로 위임한다. 피고도 새 방장이 될 수 있고 이전 방장이 복귀해도 권한을 자동 회수하지 않는다. 모두 나가면 방이 닫힌다.

방장은 `방 닫기`를 확인해 방을 종료할 수 있다. 진행 중 재판은 판결 없이 중단되며 신규 입장은 차단된다. 완료된 게임의 접근 가능한 기록은 유지된다. 방 종료로 중단된 기록은 사건과 중단 상태만 보여준다. 피고 퇴장 중단은 현재 공개 범위 결정이 보류되어 상세 내용을 표시하지 않는다. 중단은 무죄나 기권만으로 끝난 무판결과 같은 판정이 아니다.
