# 결과 화면과 내부 알파 게이트 (#18)

## 목표와 완료 범위

모바일 결과 화면은 판정·유죄/무죄/기권 수·벌칙 적용 여부를 먼저 보여준다. 유죄일 때만 수행할 벌칙을 안내한다. 무죄·무판결은 벌칙 적용 없음이 명확해야 한다. 이는 수행 체크/강제 집행 기능이 아니다. 사건, 합의했던 벌칙, 역할, 설정 시간, 초대 링크, 참가자 명단은 보조 상세 영역으로 구분한다.

완료된 1/2차 이유는 별도 라운드로 표시하고 작성자가 입력한 기권 이유도 보존한다. 빈 이유·미제출 이유는 만들지 않는다. 본인 receipt는 다른 세션에 전파하지 않는다. 익명 이유에는 작성자·세션·요청키·제출시각·명단/제출 순번을 포함하지 않고 공개 문자열 기반 중립 순서를 사용한다. 문체와 소수 인원으로 작성자를 추론할 수 있으므로 추론 불가능한 익명성을 보장하지 않는다.

## 개인정보 회귀

실제 HTTP 5세션에서 일반 G1/N0/A3, G0/N1/A3 및 전원 기권을 완료하고 모든 세션의 집계·본인 receipt·공개 이유 allowlist를 검사한다. 직접 작성한 이유 2개만 공개하고 빈 이유는 추가하지 않는다. 실제 저장소에 잘못 들어간 비대상 피고 행도 이유 공개 대상에서 제외한다.

종료 후 새 세션의 join, GET, heartbeat에서 이전 game은 null, 이전 draft 사건/벌칙은 빈 값, consent는 pending이다. 게임 참여 이력을 추가하지 않으며 이전 게임 투표 명령도 금지한다. 기존 참가자의 결과를 링크를 가진 새 방문자에게 공개하는 것은 아니다. 별도 중단 이력 정책 #33은 확정하지 않고 기본 비공개를 유지한다.

## 내부 알파와 운영 MVP 구분

이 게이트는 5개 독립 브라우저 컨텍스트로 일반판·동률 재투표·전원 기권의 주요 흐름을 확인하는 내부 알파다. 동시 연결/이탈/방장 위임/다음 게임/개인 이력 등 나머지 티켓, 전체 회복 E2E, 실기기, 외부 접속과 배포 완료를 대신하지 않는다. 하네스 보고서의 productValidation은 계속 partial이다. 구체적인 실행 수·보고서·시각 확인은 작업 기록에 남긴다.

## 시각 확인

`artifacts/results/guilty-320.png`와 `acquitted-390.png`를 직접 확인했다. 320px에서도 상단에 유죄·3/1/0 집계·수행할 벌칙이 보인다. 390px 재동률 화면은 무죄·2/2/0·벌칙 없음·2차 동률 설명을 먼저 표시한다. 익명 이유는 라운드별로 구분되고 안내가 줄바꿈되며, 사건/방 정보는 닫힌 상세로 내려갔다. 실제 모바일 기기나 OS 키보드를 검증했다는 뜻은 아니다.
