# 0001 — 제품과 독립된 최소 실행 하네스

상태: v0 구현 선택. 제품 스택의 결정이 아님.

## 선택
Node 내장 모듈만으로 검사 runner와 자체 시험을 만든다. 코드 작성은 Codex가 하고,
판정은 명령의 종료 상태와 명시된 테스트 결과를 읽어 수행한다. 문서·제품 설계와 별개로
실패를 놓치지 않는 실행 기반을 학습한다.

## 비교
- 거대한 에이전트 프레임워크: 도입 자체 학습 비용과 의존성·권한 범위가 큼. 현재 불필요.
- 훅부터 설치: 버전·신뢰·모든 도구 쓰기 경로의 의미부터 알아야 함. 먼저 선택하지 않음.
- 내장 runner: 코드가 작아 직접 읽고 결함을 주입하기 쉬움. 선택.

## 절충
Node TAP 결과에 의존하고, 테스트 이름이 파일 경로와 같으면 보수적으로 실패시킨다.
검사 코드를 수정할 수 있는 에이전트를 보안적으로 격리하지 않는다. 원격 CI와 권한·리뷰
경계는 이후 별도로 구성해야 한다.
