# ADR 0021 · 승인된 계정 삭제·여행방 보관 정책

상태: 2026-11-18 사용자 승인. 구현과 검증 진행 중이며 운영 실행 승인이 아니다.

## 승인 범위

사용자는 두 가지 구체적 질문에 동의했다.

1. 계정 탈퇴자가 참여한 판의 사건·벌칙·변론·투표 이유 등 자유 입력 내용은 다른 작성자의 분량까지 제거한다. 숫자 결과와 완료 상태만 보존하고 탈퇴자의 신원·프로필·인증을 정리한다.
2. 여행방은 자동 만료 없이 보관한다. 관리자가 삭제할 때 7일 복구 유예를 둔다. 백업은 하루 한 번 최근 7일 보관하며 최대 하루치 기록 손실 가능성을 수용한다. 계정 삭제 정보를 백업 복원으로 되살리지 않는다.

이전 추천 전체가 일괄 승인된 것은 아니다. 재가입 시 권리 복구·프로세스/전체 디스크 예산·외부 백업 보관처는 별도 미결 사항이다. 아래 추가 승인 두 항목 외 예외를 임의 확대하지 않는다. 카카오 앱 존재나 자격증명 설정도 이 승인으로 확인된 것이 아니다.

## 구현 원칙

- 탈퇴는 현재 로그인 본인의 요청과 명시 확인을 검증한다. 기존 실제 계정/방을 시험에 사용하지 않는다.
- 탈퇴자가 직접 작성한 시작 전 취소 판의 자유글도 정리한다. 타인이 작성한 미시작 판에서 단지 선택만 된 경우까지 다른 작성자의 내용을 지우지 않는다.
- 숫자 집계를 남기는 것은 자유 텍스트를 익명화했다고 부르는 것과 다르다. 원본 JSON, 결과, 영수증 등 복제 경로도 제거 대상으로 추적한다. 최소 멱등성 기록은 민감 내용을 담지 않고 재시도에 의한 작업 부활을 차단해야 한다.
- 계정에 명시적으로 연결된 과거 판도 범위에 포함하되, 연결되지 않은 다른 익명 기록의 소유권을 추정하지 않는다.
- 방 삭제는 접근 차단과 7일 내 복구, 유예 만료 후 영구 정리를 구분한다. 계정 삭제 정보나 이미 제거된 회원을 복구 과정에서 재생성하지 않는다.
- 삭제 정보의 durable ledger는 백업과 별도로 취급한다. 삭제 성공/ledger 미기록 창을 허용하지 않는다. 복원본은 최신 삭제 목록 적용·검증 전 서비스에 공개하지 않는다.
- 단일 디스크의 ledger/checkpoint가 함께 옛 상태로 돌아가면 최신성을 증명할 수 없다. 독립 최신성/보관 경계가 없는데 운영 부활 방지 완료라고 보고하지 않는다.
- 일일 백업/정리는 합성 데이터에서 검증한다. 운영 스케줄 설치, 운영 데이터 영구 삭제, 자격증명이나 보안 설정 변경은 자동으로 실행하지 않는다.

## 합격 기준

자유 입력 여러 작성자·JSON/영수증 중복·프로필/인증·권한 철회·중복/경합/재시작, 정확한 7일 경계·복구 중 권한 소실·만료 방 정리, WAL 일관성·삭제 ledger 실패/절단/구버전 복원·현재 기록 부활 차단, 모바일 확인/취소/실패/재시도를 TDD로 확인한다. 독립 리뷰 후 정확한 고정 커밋에서 전체 하네스를 수행한다. 미결/외부/실기기/운영 시험은 별도 표시한다.

## 추가 승인 · 혼자 남은 관리자와 진행 중 계정 탈퇴

사용자는 혼자 남은 여행방 관리자의 탈퇴는 방을 기존 7일 삭제 대기 상태로 전환하고, 게임 도중 계정 탈퇴도 허용하며 해당 판을 미완료로 끝내도록 승인했다. 공개하지 않은 제비는 끝까지 비공개이며 이미 공개된 숫자만 보존한다. 기존 전작성자 자유글 제거 정책은 그대로다.

- 다른 현재 멤버가 있는 관리자는 먼저 이양해야 한다. 단순 오프라인을 탈퇴나 혼자 남은 상태로 간주하지 않는다.
- 진행 중 고정 참가자/작성 진행자, 준비 중 선택 참가자/작성자가 탈퇴한 판을 중단한다. 같은 방의 미참가·미선택 멤버가 탈퇴했다고 다른 판을 중단하지 않는다.
- 솔로 방 삭제 대기와 계정 삭제를 하나의 durable 의도로 기록해 장애·복원에서도 함께 재생한다. 계정 자체는 7일 복구 대상이 아니다. 탈퇴 계정이나 그 방 복구 권한을 자동 복원하지 않는다.
- 실제 운영 삭제·배포·카카오 설정은 이번 코드 구현 승인의 실행 대상으로 간주하지 않는다.
