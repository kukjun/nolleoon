# 게임 설정 초안 (#10)

방 안의 설정이며 아직 게임은 시작되지 않았다. 현재 방장만 사건·벌칙·시간을 저장한다. 참가자는 최신 저장값을 읽을 수 있지만 직접 API로 변경할 수 없다. 실제 역할 선택·벌칙 동의·시작 조건은 #11~13에서 추가한다.

## 데이터와 명령

`POST /api/rooms/:code/settings`는 `{expectedVersion, caseText, penaltyText, durationMinutes}`만 받는다. 쿠키 신원을 서버에서 확인하고 동일 origin/CSRF 검사를 적용한다. 트랜잭션 안에서 열린 방·활성 멤버십·현재 방장·진행 게임 부재·초안 버전을 다시 확인한다.

- 사건: 최대 2,000 유니코드 코드포인트
- 벌칙: 최대 500 코드포인트
- 바깥 공백은 제거하고 줄바꿈/탭은 유지한다. 다른 제어/포맷 문자는 거부한다.
- 시간: 기본 3분, 1~10분의 정수. API는 분, 저장소는 초를 쓴다.
- 부분 초안을 보관하기 위해 빈 사건/벌칙도 저장 가능하다. 빈 내용으로 게임 시작 가능하다는 뜻이 아니다.

초안은 기존 `drafts` 행 하나가 원본이다. 게임 행은 만들지 않는다. 저장 이력이 없으면 빈 내용·3분·버전0을 반환하고 첫 저장은 버전1이다. 별도 `draft.version` CAS로 덮어쓰기를 막으므로 참가자 입장/단절/복귀에 의한 방 버전 증가가 초안 충돌을 만들지 않는다. 저장 성공은 초안 버전과 방 snapshot 버전을 함께 증가시킨다. 저장 실패는 둘 다 롤백한다.

서버 snapshot은 저장된 초안을 반환한다. 방장 이전 구현 시에도 같은 초안 원본을 읽게 된다. 실제 방장 이전 E2E는 #21 전에는 완료로 보고하지 않는다. 진행 중인 게임 행이 있다면 설정 저장을 거부하지만 실제 시작 기능은 아직 없다.

## 화면과 충돌

방에 들어온 뒤에는 마케팅 소개 대신 대기실·설정·참가자 중심으로 표시한다. 편집 중 로컬 입력은 폴링으로 덮어쓰지 않는다. 저장 중·미저장·저장 완료를 구분하고 통신 실패를 성공으로 표시하지 않는다. 버전 충돌이면 입력을 남겨두고 최신 서버 초안을 명시적으로 다시 불러온다. 다른 탭의 변경을 강제로 덮어쓰는 우회 저장은 제공하지 않는다.

## 검증

실제 API로 비방장 거부, 시간 0/11/분수/문자열 거부, 텍스트 길이, stale 버전, 동시 저장 하나 성공/하나 충돌, 참가로 방 버전이 바뀌어도 초안 저장 가능함을 검사한다. 임시 DB로 저장 중 실패 시 초안+방 버전 rollback과 DB 재개방 후 복구를 검사한다. 화면 회귀는 호스트/참가자, 저장 오류, 편집 중 폴링, 충돌·다시 불러오기, 재방문을 다룬다. 첨부·벌칙 수행 확인·게임 시작·실기기/외부 배포는 범위가 아니다.

## 화면 확인

`artifacts/settings/host-mobile.png`의 390px Chromium 캡처를 직접 확인했다. 방 참여 뒤 홈 소개 영역이 숨겨지고 대기실·초대·설정·참가자 순서로 나타난다. 사건/벌칙 입력, 제한 시간, 저장 상태와 버튼이 가로 잘림 없이 읽힌다. 실제 모바일 키보드나 하드웨어 안전영역까지 검증했다는 뜻은 아니다.

이 초안 endpoint의 진행 게임 잠금은 모든 시간 변경을 영구 금지한다는 규칙이 아니다. 투표 시작 전 시간 조절은 후속 #14의 해당 게임 명령에서 별도 권한·상태 검사를 구현한다.
