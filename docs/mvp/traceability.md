## 검증과 문서의 한계
이 표는 존재하는 REQ ID와 책임 이슈의 연결이다. 시험 설계 65개가 실제 테스트 코드로 모두 구현되었다는 뜻이 아니다. 여러 중복·폐기된 T 항목은 MVP-01에서 활성 기준선으로 정리하며 실행 여부는 제품 하네스 증거로만 판단한다.
