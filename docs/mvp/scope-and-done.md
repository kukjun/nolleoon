# MVP 범위와 완료 기준 제안

상태: **사용자 승인 MVP 범위** (2026-11-16). GitHub 이슈 #1–32 순차 실행 및 필요한 추가 이슈 생성 승인. 각 완료 기준은 미래 합격 조건이지 현재 통과 증거가 아니다.

## MVP 한 문장
친구들이 모바일 웹에서 같은 방에 모여 방장이 설정한 재판 게임을 여러 번 진행하고, 익명 투표·동률 재투표·끊김 복구·방장 이양·판별 기록을 이용할 수 있는 앱. React + TypeScript, Nest 내부 웹 BFF와 클린 아키텍처, SQLite, 맥미니·Cloudflare Tunnel을 사용한다.

## 포함 추천
1. 로그인 없는 브라우저 세션, 방 생성/초대/닉네임, 역할과 방장 권한 분리. 방장도 피고 가능.
2. 방장 게임 설정·공유 초안 저장, 최소 3명/피고 유일성/수락 버전 확인, 시작 시 접속 투표자 동결.
3. 선택 반론과 방장 개시, 1~10분 기본 3분, 한 라운드 한 표/이유, 기권, 자동 마감·집계.
4. 첫 동률 집계+익명 이유 공개→선택 최후 변론→동일 자격/기간 재투표; 두 번째 동률 무죄, 0유효표 무판결.
5. 서버 권한으로 미완료 라운드 이유 비공개, 첫 동률로 이미 공개된 1차 이유는 2차 진행 중에도 유지. 최종 양 라운드 이유와 무판결 기권 이유 공개.
6. 연결 이상/동일 브라우저 복귀, 10분 퇴장, 방장 무작위 이양, 피고 퇴장 중단·일반 퇴장 마감 기권.
7. 같은 방 다음 게임, 방 수동/전원 퇴장 종료, 게임별 접근 경계, 브라우저 개인 기록.
8. 모바일 기본 접근성, 단위/통합/E2E·보안·경합 시험, 재시작 복구·일관된 백업/복원, 외부 접속·운영 문서.

복구·권한·히스토리는 기존 대화에서 합의했고 게임 흐름과 얽혀 있으므로 초안에서 몰래 제외하지 않았다. 시간 단축이 필요하면 먼저 MVP-18까지의 **내부 알파**를 구분해 시험할 수 있다. 내부 알파를 최종 MVP 또는 외부 사용 준비 완료로 보고하지 않는다.

## 미포함
- 계정 로그인·다른 기기 신원 복구·이메일/소셜 로그인
- 사진/파일 첨부, 채팅, 원고라는 새 게임 역할, 벌칙 수행 완료 관리
- Redis/메시지브로커/마이크로서비스/독립 BFF 서버, PostgreSQL Docker
- 앱스토어 앱, 푸시 알림, 결제, 검색엔진 유입·마케팅 분석
- 자동 보관기한/장기 방 만료/관리자 개인정보 열람 UI. 다만 보안·로그 최소화·백업 범위는 필수
- 중국/다롄 현지 접속 보장 또는 현지 시험: 사용자가 완료 범위에서 제외. **일반 외부 인터넷 접속 검증은 포함**

## 적용 기준과 남은 설계 작업
- [최신 규칙](../design/00-current-rules.md)과 최신 사용자 결정이 우선. 기존 scope/API/시험의 오래된 반대 문구를 MVP-01에서 실제로 정리한다.
- 기술 합의: React/TypeScript + NestJS 내부 BFF + SQLite, Mac mini + Cloudflare Tunnel. FastAPI/Render/PG 전제는 과거 후보다.
- 라이브러리·패키지 버전, SQLite 드라이버/마이그레이션, 세션 방식, presence 감지 기준, polling/stream, 입력 길이, 자원·속도 목표는 **설계 제안**. MVP-01에서 최소 선택과 측정 기준을 기록하고 관련 구현에서 시험한다.
- 사용자 경험과 공개 범위를 바꾸지 않는 상세값은 설계자가 제안한다. **피고 퇴장 중단 기록 공개 범위**처럼 명시 합의가 없는 개인정보 경계는 구현 전 보수적 방안을 명시하고 확인하며 임의로 공개를 늘리지 않는다.
- REQ-032는 폐기. REQ-054는 같은 브라우저 복귀만 유지, 이양 없음은 폐기. 중국 접속 T-26은 이번 인수 게이트에서 제외하고 다른 시험을 통과한 것으로 대체하지 않는다.

## 전체 Definition of Done
다음이 **같은 릴리스 후보 소스 상태**에서 충족돼야 한다. 항목에 pass/failed/blocked/not-run/waived(승인 근거)를 명시한다.

### 기능·데이터
- 5개 독립 브라우저 세션이 방에 입장해 일반 판결, 첫 동률→최후 변론→재투표, 다음 게임과 이력을 완료.
- 2명 시작 거부·3명 시작 허용 및 6명 허용, 방장=피고, 후발 관전/투표 금지, 중복 선택/수락 변경/게임 간 격리 시험.
- 중복·동시 제출/마감/마지막 표 경합에서도 표·결과 단일성. 전원 기권, 기권 3+유죄 1, 미제출 마감 기권 확인.
- 연결 차단/복귀/10분 퇴장/재입장·방장 이양·전원 퇴장·진행 중 중단 확인. 실제 10분 기다림 대신 가짜 시간 시험과 실제 시간 연동 검증을 구분.
- 같은 브라우저 이력 복구, 다른 브라우저/종료 후 입장자의 과거 기록 차단. 숨겨진 표·이유·식별정보가 API/이벤트/로그에 누출되지 않음.

### 품질·하네스
- 기능별 RED→GREEN→REFACTOR 증거, 단위·DB/API 통합·전체 Playwright E2E 통과.
- lint/type/build 및 실제 검증 명령을 하네스에 연결. 빈 테스트/skip·timeout/미설정/blocked를 통과로 오인하지 않는 어댑터 자체 시험.
- 실제 iPhone Safari와 Android Chrome에서 키보드·터치·뒤로가기·잠금/복귀·오류 안내 확인. 브라우저 에뮬레이션과 실제 기기 검증을 구분. 장비가 없으면 완료 주장하지 않고 blocker로 기록.
- 최종 독립 리뷰→결함 재현 시험→수정→관련 및 전체 회귀 재실행→재리뷰. 미해결 치명/주요 결함 없음. 경미 잔여는 내용·영향·후속 이슈와 사용자 수용 여부 명시.

### 운영·접속
- 실제 DB에서 서버 재시작 후 세션/판/마감/10분 만료 복구, 중복 작업 안전성 확인.
- 백업으로 별도 임시 DB 복원 후 결과/권한/이력 검증. 운영 DB 덮어쓰기 없이 수행.
- 새 주소·포트·데이터 경로로 기존 PillWhy와 격리. 비밀·DB 파일·실제 사용자 데이터는 public repo에 미포함.
- 실제 보유 도메인 HTTPS로 **맥미니 밖의 네트워크**에서 화면뿐 아니라 join/vote/sync/reconnect 확인. localhost 확인은 대체 증거가 아님.
- 자동 시작/재시작·헬스체크·로그 마스킹·백업·롤백·맥미니 로그인/디스크/절전 조건을 운영 문서에 기록하고 승인된 설정만 적용.

## 완료 시점
날짜/소요 시간은 아직 약속하지 않는다. 32개 이슈의 AC와 위 게이트가 충족되고 최종 인수에서 남은 위험을 확인한 시점이 MVP 완료다. CI/배포 승인이나 기기 접근이 막히면 코드 완료와 인수 완료를 구분한다.
