상태: 구현·로컬 검증 완료, draft PR 검토

## 목표와 범위
웹에서 승인한 놀러온의 배경·색·카드·글자·버튼·게임 식별을 Flutter 화면으로 옮긴다. 시작 기준 d551688. 별도 UI 브랜치이며 네이티브 인증 준비 PR #214 위에 쌓는다. 실제 카카오 연동 성공은 사용자 보고이고 이 작업의 합성 시각 검증과 구분한다.

현재 로그인 시험 앱/서버·운영·사용자 계정·플랫폼 설정은 수정하지 않는다. 제품 규칙, API, 저장소 키, 데이터 마이그레이션은 범위 밖이다.

## 기준과 가정
`apps/web/src/travel.css`와 실제 여행방 렌더가 우선이다. `design/styles.css`, `design/party-tokens.css`, `design/party-layout.css`의 값은 적용 scope/화면을 확인하고 사용한다. 과거 파란 party 토큰과 현재 여행방의 녹색 텍스트를 임의로 혼합하거나 Material seed에서 근사색을 자동 생성하지 않는다.

## 합격 기준
- 같은 390×844 합성 상태에서 홈, 방/로비, 게임 선택, 대표 진행/결과의 전후 렌더를 보관하고 비교한다.
- 색 대응표와 실제 소스 위치로 공통 토큰을 설명한다. 웹에 없는 색/요소는 새 승인 디자인으로 단정하지 않는다.
- 최소 48px 터치 영역, 좁은 폭 및 큰 글자에서 안전한 줄바꿈/스크롤, 단계 이동·취소·중복 클릭 보호를 유지한다.
- 관련 widget 회귀, analyzer, 전체 Flutter 테스트를 최종 통합 코드에서 실행한다.
- 독립 리뷰는 소스 및 실제 렌더 둘 다 확인한다. 합성 캡처는 실제 로그인·물리 기기 검증으로 표시하지 않는다.
- 별도 draft PR로 제공하고 운영/사용자가 로그인한 시뮬레이터에는 설치하지 않는다.

## 실행과 증거
- 제품 소스 de56652, 통합 회귀 보강 707273c: Flutter 전체 **279 PASS**, analyzer clean. 최초 278 PASS/1 FAIL은 기존 통합 fixture가 새 게임선택 단계를 건너뛴 경우였으며, 단계·참가자 비노출 단언을 추가해 기존 취소/결과 검증을 유지했다.
- 최종 캡처 보강 6e470f9: BEFORE d551688와 AFTER de56652의 동일 390×844 합성 화면 6쌍, 별도 웹 6장. 두 Flutter 렌더 각 1 PASS, 한글 fontFamily 보충 및 실제 공개 preset 디코딩 대기를 같은 조건으로 적용했다. 원래 캡처는 덮어쓰지 않고 보존했다.
- `comparison-verified/index.html`, `contact-sheet.png`, `manifest.json`과 18 PNG가 결과다. 해시/폰트 정책/소스 범위는 manifest와 [캡처 문서](../mobile/style-evidence.md)에 명시한다. 화면은 실제 위젯/브라우저 렌더지만 API는 합성이며 OS 캡처·실제 Kakao·실기기 검증이 아니다.
- 초기 빈 로비 아바타는 widget fake clock이 실제 이미지 디코딩 완료를 기다리지 않은 캡처 결함이었다. 공개 preset precache + RenderImage 이미지 존재 단언 후 정상 표시를 확인했다. 제품 아바타 로직은 변경하지 않았다.
- 독립 소스 및 6화면 시각 검토로 이번 개선 범위를 승인받았다. 웹과 완전 동일하다는 의미는 아니다: 홈 관리 메뉴 배치, 결과에서 본문 로비 CTA 대신 AppBar 뒤로가기 등은 유지했다.
- 별도 draft PR #215는 #214 위에 쌓였다. 실제 로그인 중인 앱·서버와 운영은 변경/배포하지 않았다. 원격 CI는 미설정이며 통과로 주장하지 않는다.
