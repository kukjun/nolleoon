# #114 모바일 게임 기록 카드 폭 복구

공개 서비스의 실제 3게임 기록 화면에서 제목이 한 글자씩 세로로 눌리는 현상을 확인했다. 카드의 flex 행 안에서 공통 버튼 `width:100%`와 축소 금지가 제목의 가용 폭을 없앴다.

변경은 기록 카드 CSS에 한정한다. 버튼 폭을 내용 기준으로 되돌리고 제목에는 유연한 최소 읽기 폭을 둔다. 큰 글자로 한 줄에 놓기 어려우면 버튼을 다음 줄로 이동한다. 게임·기록 접근 권한·서버 정책은 바꾸지 않는다.

합성 기록 fixture의 320/390px 및 텍스트 100/200% 네 경우에서 제목 컨테이너 폭 0px로 RED를 확인했다. 수정 후 네 경우 모두 제목 폭 120px 이상, 버튼 44×44px 이상, 제목/버튼 비중첩, 카드/화면 바깥 넘침 없음으로 통과했다. 기존 실제 기록 동작 2개와 함께 6/6, 별도 기존 모바일 에뮬레이션 3/3을 확인했다. 빌드도 통과했다.

수정 후 390px 기본 글자 캡처에서 세 게임 제목이 정상 가로 배치되고, 320px 200% 텍스트 캡처에서는 버튼이 제목 아래로 내려가 읽기 쉬움을 직접 확인했다. 200% 시험은 DOM 글자 크기 근사이며 실기기 글꼴 설정 검증은 아니다. 공개 배포는 이 작업에서 수행하지 않았다. 전체 최종 검증과 배포 후 재확인은 별도다.
