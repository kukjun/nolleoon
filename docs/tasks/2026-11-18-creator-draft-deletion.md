# 계정 탈퇴 시 본인이 작성한 미시작 취소 판 정리

상태: 검증 완료 (운영 미적용)

## 목표와 경계
실제 참가 행이 없는 미시작 판도 탈퇴 계정이 작성자이면 삭제 저널의 runIds에 포함한다. 기존 숫자 집계/상태와 타인의 내부 권한 증거는 유지한다. 타인이 만든 판에 selected로만 지정된 계정으로 삭제 범위를 확대하지 않는다. 기존 redactRun 경로가 설정/상태/결과 및 run ID를 담은 재시도 영수증 복사본을 함께 정리한다.

## 보호 조건
작성자 멤버십이 이미 퇴장한 비정상 과거 상태여도 draft/active 판이면 탈퇴를 차단한다. 관리자 제한과 기존 참가자/연결 레거시 보호는 그대로 유지한다. 새 스키마나 운영 데이터 변경은 없다.

## 실행과 증거
신규 DB 시험 2개는 기존 구현에서 각각 저널 runIds 누락, active/draft 작성자 제한 누락으로 실패(RED)했다. repository 쿼리 수정 후 신규 2개 및 기존 계정 탈퇴 DB/API/복원 회귀를 합쳐 13개 PASS. 전체 build 및 변경 파일 ESLint PASS. 같은 탈퇴 명령 재시도 시 저널 중복 없음, 취소 상태와 0명/빈 라운드 집계 보존, 다른 작성자 판의 설정과 영수증 유지도 확인했다.

전체 하네스/운영 검증은 별도 통합 단계다.
