# PARTY 기존 브라우저 회귀 연결 (#97)

## 목표와 경계

기존 재판 74개 기능·3개 전체 흐름·3개 모바일 에뮬레이션 시험을 새 대기실/게임 선택/준비 단계 UI에 연결한다. 권한·비공개 정보·중복 요청·마감·입력 보존의 기존 검증을 삭제하거나 skip하지 않는다. 새 파티 시험은 별도 gate에서 실제 실행하며 기존 집계와 중복하지 않는다. 실기기/외부 배포 인수를 의미하지 않는다.

## 변경 원칙

- `openCourt`는 실제 버튼으로 게임 선택과 준비 단계를 이동한다. 다른 탭에서 돌아온 경우 focus 이벤트의 실제 서버 조회를 기다린다. 숨긴 DOM을 강제 노출하거나 직접 API로 준비를 대신하지 않는다. 깨끗한 방장 준비 재진입은 실제 UI가 선택 PUT을 다시 보내므로 호출부에서 이를 명시한다. 선택된 게임이 이미 재판임을 확인하고 준비 세대·초안·역할 revision·동의가 변경되지 않았음을 비교한다. 다른 게임을 재판으로 몰래 바꾸어 회귀를 통과시키지 않는다.
- 역할·동의와 설정이 다른 단계이므로 미저장 벌칙과 저장된 벌칙 동의의 동시 검증은 같은 브라우저의 두 탭으로 수행한다. 미저장 값 보존·기존 벌칙 거절·저장 후 새 동의 검증을 유지한다.
- 사건 상세/이전 라운드 이유는 실제 모달을 열고 내용 확인 후 닫는다. 모달을 생략해 개인정보 검증을 삭제하지 않는다.
- 개인 이력 목록은 사건 제목 대신 게임 종류·상태를 보여준다. 해당 항목의 상세를 열어 원래 사건·판정 확인을 유지한다. 페이지 fixture도 실제 새 계약으로 20→21개/커서/비중복 검증을 수행한다.
- 파티 네트워크 오류와 방 heartbeat 오류가 동시에 존재할 수 있으므로 연결 복구 검증은 `data-reconnecting` 알림을 지정한다. 복귀 후 전체 알림 소멸 검증은 그대로 둔다.

## 실행 근거 (진행 중)

- 처음 기존 시험 fail-fast: 닫기 2개, 동의 3개가 숨겨진 준비 단계에서 실패했다.
- 닫기 단계 연결 후 3/3 통과.
- 동의·설정·역할 재검증 10/10 통과(30.95초), start 포함 앞선 집합 9/13에서 남았던 단계 접근 문제를 수정했다.
- 31개 진행/복구/결과 집합 22 통과·9 실패. 모달/시간 disclosure 경로를 연결하고 중복 알림 선택을 구체화했다. 별도로 실제 결과 배치 회귀(320px 집계 시작 y=212, 기존 기준 <180)를 발견해 제품 수정 요청했다. 기준을 완화하지 않았다.
- 최종 전체 결과는 실행 보고서와 커밋 검증 기록으로 따로 남긴다. 이 문서 자체는 전체 통과 증거가 아니다.

## 새 실행 gate

루트 Playwright 설정은 `party-*.spec.mjs`, `avatar-picker.spec.mjs`만 제외하고, `playwright.party.config.mjs`는 정확히 그 파일만 실행한다. 새 설정 안에서 `@party-e2e` 여부로 기능/전체 흐름을 배타적으로 나눈다. 두 gate 모두 동일 JSON 정규화로 0개·skip·flaky·실패를 통과시키지 않는다. 기존 360/150/90초 예산은 유지하고 새 파티 기능/여정은 각각 180초 예산이다. 루트 기본 15초·기존 파티 기본 20초·개별 시험의 명시적 예산 및 assertion 제한과 retries=0은 유지한다. 기존 UI 개발용 4184 서버 대신 두 gate는 순차 실행되는 공통 소유 fixture/4179 서버를 사용한다.

## 전체 진단 실행

기존 80개 실제 실행에서 기능 67/74, 기존 다인 E2E 3/3, 모바일 에뮬레이션 3/3으로 총 73 통과·7 실패·skip/flaky 0이었다(393.3초). 실패는 홈 안내 문구 2개, 준비 중 방장 표시 선택 1개, 긴 사건 시작 단계 접근 1개, 결과 y=212 배치 회귀 1개, 모달 제목/버튼 동명 선택 2개였다. 결과 배치 제품 수정은 별도 UI 커밋에서 수행했고 기존 <180 기준을 유지한다. 나머지는 현재 UI의 공개 동작 경로로 연결했다. 진단 실행 도중 이후 파일의 시험 연결 변경이 있었으므로 이 집합을 최종 고정 RC 증거로 사용하지 않는다. 최종 커밋은 독립 깨끗한 소스 검사 대상이다.

## 수정 후 영향 검증

리뷰가 지적한 선택 PUT의 숨은 부작용과 이력 행 식별을 명시적으로 보강했다. 결과·재투표·개인 이력·설정 12개 영향 시험은 12/12 통과(76.79초, skip/flaky 0). 결과의 기존 <180px 조건을 유지했고, 중복 초대 입력은 결과 disclosure 안에서 확인하며, 스크린샷은 실제 결과 영역을 지정한다. 새 gate 계약 6개와 lint도 통과했다. 새 파티 전체 흐름 및 최종 고정 소스 전체 검사는 별도 보고서에 기록한다.
