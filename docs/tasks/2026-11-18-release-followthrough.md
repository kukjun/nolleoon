# 여행방 잔여 출시 게이트 후속

## 목표와 경계

사용자의 후속 진행 요청에 따라 안전하게 독립 실행 가능한 작업을 진행한다. React 웹만 대상이다. 운영은 브랜드-only 기존 API이며 PR #145를 게이트 통과 없이 출시하지 않는다. 실제 계정 unlink/영구삭제, 인증키·네트워크·운영 설정 변경은 이 문서로 승인하지 않는다.

## 작업과 합격 기준

- 실제 OAuth 기존 증거와 합성 시험, 운영/실기기 미검증 범위를 문서에서 구분한다.
- remote unlink의 안전한 adapter를 합성 검증하되 삭제 원자성/subject 보관 정책 미결을 감추지 않는다.
- 일일 백업 신선도와 용량의 읽기 전용 운영 점검을 합성 시험한다. 스케줄/실제 prune는 실행하지 않는다.
- 원격 CI·실기기·Kakao 표시명 및 Library 전달 접근을 점검하고 불가한 항목을 그대로 남긴다.
- 변경의 정확한 SHA, TDD·독립 리뷰 및 전체 검사 근거를 남긴다.

## 기존 근거

직전 clean RC d0947d1은 전체18gate/631test 통과. 운영 브랜드-only #154는 외부 HTTPS/390px GET 확인을 마쳤지만 새 여행방 외부 다인 인수의 근거가 아니다. 실제 사용자 localhost3102 로그인은 별도 격리 환경에서 성공했고, 후속 읽기 전용 점검에서 활성 계정1·유효 세션1과 health200을 확인했다. 이 집계는 사용자의 브라우저를 직접 조작한 시험이나 실제 provider unlink 성공을 뜻하지 않는다.
