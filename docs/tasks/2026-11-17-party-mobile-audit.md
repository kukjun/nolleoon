# PARTY-23 모바일 접근성 독립 검사

## 목표와 경계
기준 e7086d2의 신규 파티 화면을 320/360/390으로 확인한다. 신규 제품 규칙, 서버 권한, 운영/배포 변경 없음. 새 테스트3개와 확대 가독성 CSS 수정만 포함한다.

## 합격 기준
문서 가로 넘침 없음, 노출 버튼/아바타 선택44px, 키보드 모달복원·polling 비간섭, 로비 CTA 회전 근사 전후 접근, reduced-motion, 장문 벌칙 전문, 확대 시 참가자 이름 폭을 확보한다. 물리 기기는 별도 미완료다.

## 실행과 실패 해석
최초 party config가 기반4179를 상속함을 실행 JSON에서 발견했다. reuseExistingServer:false로 자체 fixture가 실행/종료했지만 최종 증거에서는 제외하고 ignored 전용 config로4184에서 재실행했다. 기본화면3개 통과 후 확대 스크린샷에서 명단 이름의 세로 나열을 발견했다. 첫 시험은 첫번째 참가자를 검사해 순서에 따라 문제대상을 놓쳤다. 정확한 긴 이름 참가자를 지정한 뒤 폭22.5px 대 기준104px RED를 재현했다. CSS grid 2행 배치로 고친다. assertion 완화 없음.

증거 위치: ignored `artifacts/party-mobile` 아래 폭별9화면 PNG와 CTA 좌표/대비 metrics JSON. 로비/선택/프로필·제비 enlarged 화면을 픽셀 확인한다. 실기기·소프트키보드·잠금복귀·screen reader는 미실행.

## 최종 결과
build·전체 lint·typecheck PASS. 4184 전용 fixture에서 신규3개 PASS(23.3초), skipped/retry 없음. 주요 버튼 대비5.93:1. 로비 CTA top/height는 320에서562.44/56px, 360과390에서591.94/56px이며 가로 viewport 왕복 후 같은 좌표였다. 정상 크기24개 및 확대3개 화면(폭별9개) 생성. 수정 후 320 확대 이름이 정상 가로 읽기 순서로 표시됨을 실제 픽셀 확인했다. 로비/선택/프로필/제비화면도 직접 확인했다. 전체 하네스·실기기 미실행은 별도다.
