# 여행 계정·로비 UI (#124 / #128)
상태: 진행

## 목표와 경계
새 `/travel` 모바일 흐름: 로그인 안내 → 내 여행방 → 초대/가입 → 여행 로비 → 게임 선택. 기존 `/` 익명 게임과 아바타를 보존한다. 실제 카카오 앱 설정·배포·운영 데이터 변경 없음. 메뉴 게임 규칙과 #119 미정 정책은 확정하지 않는다.

## 합격 기준
- 비로그인 초대는 일반 안내만, 계정/멤버/게임 정보 없음. 로그인 복귀는 검증된 내부 초대 경로만.
- 계정 변경·세션 만료 후 이전 계정의 명단/방을 표시하지 않음. 오래된 비동기 응답 무시.
- 영속 멤버십과 연결, 방 관리자와 진행자 구분. 종료 방 읽기 전용.
- 320/390px, 긴 이름, 오류/빈 상태, 재시도, history, 중복 동작 검사.
- 서버 미구현/외부 인증 미설정은 실제 완료처럼 표시하지 않음.

## 실행과 증거
독립 worktree. API 계약은 인증·여행방 담당과 조율 중. mock HTTP UI 검증과 실제 통합 검증은 별도 기록한다.

## 게임·권한관리 후속
- 실 API 경로 계약에 맞춘 팀/제비/재판/메뉴 판 생성·시작·액션·조회, draft 수정/취소, 페이지네이션 기록 클라이언트 추가. 서버와 실제 통합은 코디네이터가 별도 검증한다.
- 이양/내보내기/퇴장/초대 폐기 확인 UI. 현재 권한/버전 검사 응답을 따르고 활성 판 이탈 미정은 막는다.
- 재판 restricted projection은 추가 필드가 있어도 사건·사유를 렌더하지 않는다. 이유는 익명, all-abstain은 무죄가 아닌 판결 없음 표시. 제비 미공개값이나 타인의 메뉴 후보를 표시하지 않는다.
- 브라우저 16/16 PASS (mock HTTP), client/projection unit 7/7 PASS, build/typecheck/scoped lint PASS. 실제 다인/Kakao/SQLite 통합 및 전체 하네스는 별도 미실행.
- mobile 320/390 팀 설정/참가 선택 screenshot 생성. 320 실제 픽셀 확인. 사용 중인 Vite 포트는 실제 통합 서버와 분리 필요.
- production `/travel` deep-link 정적서빙은 Vite 테스트로 검증되지 않는다. 코디네이터가 발견해 별도 서버 회귀를 구현한다.
