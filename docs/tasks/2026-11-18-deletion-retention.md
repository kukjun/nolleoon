# 계정 삭제·여행방 유예·백업 보관 실행

## 목표

[ADR 0021](../decisions/0021-account-deletion-and-room-retention.md)의 두 승인 정책을 구현한다. 기준선 `658274c`는 clean이며 이전 18개 자동 gate/539개 시험이 통과했다. 새 작업의 통과 증거로 대체하지 않는다.

## 경계

실제 데이터 삭제·운영 백업·스케줄·배포·자격증명·설정은 변경하지 않는다. 미확정 마지막 관리자/활성 판 예외 등은 보수적으로 차단하고 미결로 남긴다. 기존 WIP를 보존한다.

## 계획과 확인

계정 삭제/스키마, 방 삭제·복구/스키마, 삭제 ledger·일일 백업 도구, 모바일 UI를 분리해 TDD로 구현하고 통합한다. legacy 연결 기록과 최소 멱등성 tombstone도 검토한다. API/DB/UI 통합 시험 및 독립 검토·수정·재검토 이후 정확한 새 RC 전체 검사를 기록한다. 현재는 진행 계획이며 성공 결과가 아니다.
