## 실행·완료 기준
- 각 기능: RED → 최소 구현 GREEN → 리팩터 → 관련 회귀 시험. 실제 명령/종료 코드/시험 수/skip/환경/commit을 티켓에 기록한다.
- 단위: 판결, 상태, 자격, 마감, 이양 후보. 주입한 clock/random으로 경계 재현.
- 통합: 실제 SQLite 제약/transaction/재시작, HTTP 세션과 game/round 권한, 공개 DTO 누출, 중복/경합.
- E2E: 독립 브라우저 컨텍스트 최소3·5·6명. 정상 판결·동률·전원 기권·재접속·이양·후발 관전·다음 판·방 종료.
- 실제 모바일: iPhone Safari/Android Chrome 및 PC에서 실제 버전과 키보드/복귀/네트워크 전환 기록. 에뮬레이션으로 실기기 합격을 대체하지 않음.
- 배포: 외부 네트워크에서 HTTPS 도메인 접속과 실제 게임 흐름 확인. 중국 현지 시험은 제외.
- 독립 리뷰 후 지적을 수정하고 회귀 시험을 다시 실행한다. 미결정 #33은 해당 노출 기능의 합격을 막고 독립 기능은 진행한다.
- 하네스 자체 시험은 `node tools/harness/check.mjs`, `node --test tests/harness/runner.test.mjs`. 제품 suite가 미구성이면 not-configured이고 성공으로 치지 않는다.
