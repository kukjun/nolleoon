# 기준선 커버리지

REQ-001~070 중 REQ-032는 폐기, REQ-054는 신원 복구만 유지한다. [요구 표](04-requirements.md)→[SC-01~36](03-mobile-flows.md)→[T-01~65](09-verification.md)로 연결한다. T-22 폐기, T-26 MVP 제외. 나머지는 실행해야 할 계획이지 구현/합격 선언이 아니다.

기존 UI 목업은 단일 브라우저 표현 참고일 뿐 다인 동기화·서버 권한·SQLite 저장·재접속·실제 배포를 증명하지 않는다. 최신 규칙과 다른 목업 행동은 승인된 규칙으로 간주하지 않는다.

MVP-01은 문서 충돌 정리와 최소 ADR·문서 계약 시험만 수행한다. 기능 구현·제품 단위/통합/E2E·실기기·외부 접속은 후속 티켓에서 실행한다. 피고 퇴장 중단 기록의 공개 필드는 #33 결정 대기다.
