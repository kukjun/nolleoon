# 1단계: MVP 범위 초안

> 24차 일괄 확정: [최신 예외 규칙](00-current-rules.md)이 아래 과거 미정/제안보다 우선한다. 1~11 승인 및 25차 이유 공개 확정. 첫 동률 집계+익명 이유 공개, 최종 양 라운드 이유·무판결 기권 이유 공개.

> 23차 사용자 정정(이전 역할 가정 대체): 방장은 방 관리·게임 설정·시작 권한이며 게임 역할과 독립이다. 게임을 만든 뒤 역할을 선택하고 방장도 피고가 될 수 있다. 피고는 무작위 방장 이양 후보에서도 제외하지 않는다. 작성자=원고/방장≠피고 가정은 폐기하며 원고 역할은 정의되지 않았다.

> 22차 우선 적용: 끊김 후 10분 미복귀는 나감, 전원 나가면 방 종료. 방장 10분 미복귀 시 남은 참가자 중 무작위 이양(없으면 종료). 이전 이양 없음/방장 부재 시 새 방 필수 규칙은 대체되었다. 이양 후보 접속 기준·자발적 방장 나가기 세부는 미정.

> 최신 도메인 기준(20차): 같은 방에서 사건을 순차 진행하며 기존 참가자는 재입장하지 않는다. 사건마다 피고·벌칙 수락·투표 자격을 새로 정한다. 아래 이전 차수의 사건 링크/참가자 모델은 사건 내부 정책의 이력이며, 방과 사건을 분리해 읽는다. 21차에서 방 링크 유지·방장만 게임 설정·사건별 기록 접근·방 종료가 추가 확정되었으며 이후 결정이 과거 미정 문구보다 우선한다. 세부 미정은 02-open-questions.md 참조.

상태: 25차 사용자 답변 반영 / 2~5단계 전체 초안 준비 · 2026-11-16

## 결론

여행 중 친구들이 휴대폰으로 사건을 올리고 반론·투표·판결을 즐기는 작은 재판 게임이다. **사건 작성자가 벌칙을 직접 미리 작성한다**는 규칙은 확정했다. 모바일 웹·닉네임·사건 링크 참여, 역할별 투표 자격, 이유 필수 및 종료 후 익명 공개, 시작 전 피고의 벌칙 확인/거절과 시작 후 변경 금지를 추가 확정했다. 최소 3명부터 시작하며 5명을 초과할 수 있다. 피고가 거절하면 작성자가 수정·재제안하고 수락을 받은 뒤 작성자(방장)가 시작한다. 방장 재판 시작 시점의 투표자 명단이 고정되며 이후 입장자는 투표하지 못한다. 투표 시간은 기본 3분이며 방장이 투표 전 조절하고 시작 후 고정한다. 전원 제출 시 자동 결과, 직접 기권 선택이 가능하고 만료 시 미제출도 기권이다. 기권은 유죄/무죄 유효표에서 제외하며 유죄 1표·기권 3표는 유죄가 된다. 0표는 판결 없이 종료한다. 전원 직접 기권도 실질 유효표 0으로 판결 없이 종료한다. 반론은 선택이다. 연결 끊김을 표시하고 동일 참가자는 시간 내 재접속·투표할 수 있다. 조기 종료는 두지 않는다. 첫 동률은 최후 변론 후 재투표, 두 번째 동률은 무죄다. 기권 이유는 선택이고 방장이 투표를 동시에 시작한다. 첫 동률 후 피고 최후 변론은 선택이며 방장이 같은 투표자·원래 설정한 투표 시간으로 재투표를 시작한다. 재투표 전에는 1차 집계·익명 이유 공개(25차 정정)하고 익명 이유는 최종 판결 뒤 공개한다. 기권을 제외하고 유죄/무죄 중 더 많은 쪽으로 판정하며 직접 기권은 제출 완료에 포함한다. 일반/최후 변론 작성·건너뛰기 후 방장이 개시하며 무응답 진행도 가능, 피고 종료 안내와 별도 타이머 없음이 확정이다. 투표자 고정은 방장 재판 시작이다.

| C-28 | 기권 제외 유죄/무죄 중 더 많은 쪽이 판정된다 | G>N 유죄, N>G 무죄. G=N>0은 기존 재투표 규칙, G+N=0 무판결 |
| C-29 | 직접 기권은 제출 완료에 포함, 만료 미제출은 기권 | G+N+A가 자격자 수이면 자동 라운드 종료. 전원 직접 기권도 즉시 무판결 종료 |

| C-30 | 일반·최후 변론은 피고가 작성하거나 건너뛸 수 있으며 완료 후 방장이 투표를 시작한다 | 무응답이면 방장이 변론 없이 시작 가능, 피고에게 변론 종료 안내. MVP 별도 변론 타이머 없음 |

## 확정된 기본 흐름과 아직 빈 부분

사건·벌칙 작성 → 링크 공유 → 닉네임과 역할(피고/참여자) 선택 → 피고의 벌칙 수락 → 작성자(방장)의 시작 → 반론·투표 → 최종 결과 후 익명 표·이유 공개(1차 동률은 집계·익명 이유 공개(25차 정정)).

- 피고 한 명, 피고를 제외한 참여자가 투표한다.
- 반론은 선택이며, 횟수·반론 종료와 방장의 투표 시작 전제조건, 비동률 유죄 임계값·마감 경계 처리 기준은 아직 결정하지 않았다.
- 투표 기본 3분을 방장이 투표 전 조절하며 시작 후 고정한다. 전원 완료 시 자동 결과, 직접 기권과 만료 미제출 기권은 유죄/무죄 유효표에서 제외한다. 유죄 1표·기권 3표는 유죄다. 0표 및 전원 직접 기권의 무판결 종료는 확정이다. 수동 조기 종료는 없다. 연결 끊김 감지만으로 명단을 줄이거나 즉시 기권으로 바꾸지 않는다.
- 피고가 벌칙을 거절하면 작성자가 수정·재제안한다. 피고 수락 전에는 시작할 수 없다.
- 최소 3명(피고·다른 참가자)이며 5명을 초과할 수 있다. 방장 재판 시작 시점의 투표자 명단을 고정하고 이후 입장자는 투표하지 못한다.

## 익명 공개의 한계 — 논의 필요

결과에 작성자 이름을 표시하지 않아도 작성자를 추론할 수 있다. 최소 3명에서 피고 제외 투표자는 2명이므로, 각 투표자는 자신의 표·이유를 빼면 상대방의 표·이유를 알아낼 수 있다. 인원이 더 많아도 표현·맥락·자기 공개 등으로 추론할 수 있으므로 익명성을 보장하지 않는다.

확정한 것은 이름 없이 표·이유를 공개한다는 방향이다. 이 한계에 대한 사용자 안내, 소수 인원에서 이유 공개 방식 변경 여부, 호스트·운영자 접근 범위는 논의해야 한다. 숫자만 늘려 익명성이 보장된다고 표현하지 않는다.

## MVP 추천안 — 아직 제안

- 기본 검증은 친구 5명이 각자 휴대폰으로 한 사건을 끝내는 흐름으로 한다. 이는 시험 규모 제안이지 인원 제한 결정이 아니다.
- 동일 기기·브라우저 자동 복원과 시간 내 투표, 중복 투표 방지는 확정. 다른 기기/브라우저의 닉네임 일치로 기존 자격을 복구하지 않는다.
- 네트워크 단절·새로고침·중복 클릭을 안전하게 처리한다. 상세 기대 행동은 2~3단계에서 정의한다.
- 독립 사건 링크와 참가자의 참여 게임 개인 기록 방향은 확정. 영구 방·기록 상세·보관/삭제 정책은 별도 결정한다.

## 범위 밖 추천안 — 아직 제안

결제, 공개 커뮤니티, AI 판사, 자동 영상 촬영/게시, 실명 인증, 앱스토어 네이티브 앱, 대규모 운영. 실제 갈등 해결과 법률 판단은 제품 목적이 아니다.

## MVP 성공 기준 후보

1. 서로 다른 5개 클라이언트로 사건 링크 참여부터 판결까지 끝내는 시나리오를 시험한다(시험 규모 후보).
2. 각 단계에서 할 수 있는 행동과 다른 참가자를 기다리는 상태를 구분할 수 있다.
3. 벌칙이 재판 전에 피고에게 표시되고 시작 후에는 변경되지 않는다. 거절 시 수정·재제안하고 피고 수락 후 방장이 시작한다.
4. 동일 참가자의 중복 제출로 표 수가 늘어나지 않는다.
5. 화면 잠금/복귀·새로고침 이후 참여 상태와 진행 상황을 복구한다(복구 보장 범위 결정 후 구체화).
6. 투표자 전원이 제출하면 수동 종료 없이 결과 화면이 공개된다. 직접 기권의 제출 완료 취급과 기권 이유 필수 여부는 상세 확인한다.
7. 연결 끊김 감지를 검증한다. 감지 시간·표시 방식·오탐 기준은 후속 설계에서 정한다. 동일 참가자의 재접속 후 남은 시간 내 투표를 별도로 시험한다.
8. 직접 기권·마감 미제출을 유죄/무죄 집계에서 제외한다. 유죄 1표·기권 3표가 유죄가 되는지 시험한다. 0표는 무죄가 아닌 판결 없음으로 종료한다. 전원 직접 기권의 무판결도 검증한다. G/N 다수 판정과 직접 기권 완료 포함을 검증한다. Q-26 기대값은 방장 재판 시작 고정으로 검증한다.

위 항목은 제품 검증 후보이며 테스트가 구현됐거나 통과했다는 뜻이 아니다. 응답시간 목표·보관기간 등 수치는 근거 없이 고정하지 않는다.

15차 Q-26 해결: 명단 고정은 **방장의 재판 시작**이다. 첫 투표 개시가 아니며 반론 중 입장자도 1·2차 투표 불가. 동일 참가자 재접속은 신규 입장과 다르며 기존 자격 유지. 진행 중 링크 참여 가능 및 종료 후 기존 참가자만 결과·이유라는 접근 정책은 유지하되 추가 관전 정보 범위를 추정하지 않는다.

16차로 일반/최후 변론 종료 전제는 확정했다. 작성/건너뛰기 또는 방장의 무응답 진행 후 투표 개시. 별도 변론 타이머 없음. 이는 진행 중인 투표를 조기 종료할 권한과 다르며 투표 조기 종료 금지는 유지한다.

## 17차 대기실 역할·명단 확정

| C-31 | 재판 시작 전 참가자가 역할 변경 가능, 피고는 한 명 | 방장도 피고 가능. 시작 뒤 역할 변경 불가 |
| C-32 | 방장은 끊겼거나 떠난 사람을 대기 명단에서 제거 가능 | 영구 차단이 아니며 제거된 사람은 재판 시작 전 재입장 가능. 시작 후 제거/자격 축소 권한 없음 |

## 18차 시작 준비 확정
C-34: 접속 중인 서로 다른 참가자 최소 3명(방장·피고 포함, 두 역할 겸임 가능)이어야 시작한다. 피고는 현재 벌칙을 수락해야 하며 벌칙 변경 시 수락 무효화·재수락 필요. 조건 미충족이면 부족 조건을 보여준다. 끊김 인원은 최소 인원에서 제외한다. 19차에서 시작 시 접속 중인 자격자만 동결 명단에 포함하는 것으로 확정했다.

## 19차 시작 시 접속자 자격 확정
C-35: 방장 재판 시작 시 접속 중인 피고 외 자격자만 동결 투표자 집합에 넣는다. 명단에 남았어도 당시 끊긴 추가 참가자는 제외하며 이후 복귀해도 해당 재판 1·2차 투표 불가. 이미 자격을 얻은 참가자가 이후 끊겼다가 복귀하는 경우는 기존 자격 유지. 관전·조회는 기존 승인 범위만 유지하고 추가 공개 권한은 부여하지 않는다.

## 20차 도메인 변경 확정
C-36: 하나의 방에서 여러 사건을 순차 진행한다. 기존 참가자는 다음 사건마다 다시 입장할 필요가 없다. 각 사건마다 피고를 다시 정하고 벌칙 수락 및 투표자 동결을 새로 수행한다.
이전 “한 사건”은 한 재판에 피고 1명이라는 사건 단위 규칙으로 유지하되, 서비스/방당 사건 하나 제한으로 해석하지 않는다. 사건 재사용 대신 새 사건 레코드 생성이 설계 제안이다. 다음 사건 작성자·방장 유지/변경·방 링크/사건 링크·사건 참여/기록 접근·방 최대 유지 시간은 미정. 기존 단일 사건의 작성자=원고=방장 가정을 폐기한다.

## 21차 최신 확정: 방 설정·접근·종료
- 흐름: 방 생성 → 방 안에서 게임 설정 → 플레이 → 같은 방에서 다음 게임 설정. 방 링크는 유지한다.
- 매 게임 설정은 방장만 한다. 방장이 시작하며 방장도 피고를 선택할 수 있고 참가자의 시작 전 본인 역할 선택/변경을 유지한다. 방장이 피고를 강제로 지정할 권한을 추가하지 않는다. 사건·피고·벌칙·시간을 게임별 설정으로 구성하는 UI 세부는 제안이며 시간 기본값 승계 등은 미정이다.
- 게임 1 종료 뒤 방에 들어온 사람은 게임 1 결과·이유를 볼 수 없고 게임 2에는 참여할 수 있다. 게임 1 참가자는 자기 기록에서 게임 1을 조회한다. 서버는 방 멤버십이 아닌 게임별 참여 권한을 검사한다. 24차: 진행 중 후발 참가자는 투표 불가·진행/최종 결과 조회·자기 이력 허용.
- 방장은 방을 종료할 수 있다. 종료 방에서는 신규 참가·신규 게임을 받지 않는다. 완료된 이전 게임은 해당 조회 자격자의 개인 기록에 남는다. 진행 중인 게임은 중단/판결 없음으로 처리한다. 24차: 방 종료 중단 이력은 중단·사건 내용만, 미완료 표·이유 비공개.
- 방장 복구는 같은 브라우저로 한다. 돌아올 수 없으면 새 방을 만든다. 이전 '새 사건' 안내를 방 모델에 맞춰 대체하며 MVP 이양은 추가하지 않는다. 자동 만료 시간은 미정이다.
- 기존 투표 조기 종료 금지는 정상 라운드 마감을 방장 임의로 당겨 판결하는 기능에 적용한다. 방 종료는 별도 명시적 예외로 진행 게임을 **중단·무판결** 처리하며 제출된 표로 승패를 계산하지 않는다.

## 22차 나가기·복구·방장 이양 확정
- 명시적 나가기는 즉시 나감으로 처리한다. 연결이 끊긴 사람은 10분 안에 돌아오지 않으면 나간 것으로 처리한다. 10분 안 같은 브라우저로 복귀하면 기존 참가 신원을 복원한다. 연결 끊김을 즉시 나감으로 처리하지 않는다.
- 모두 나가면 방이 종료된다. 방장의 명시적 방 종료 기능도 유지한다. 투표 마감은 별도로 진행하며 연결 복구 유예 10분이 투표 시간을 연장하지 않는다. 동결 투표 자격과 접속/나감 상태를 혼동하지 않는다.
- 방장이 끊긴 뒤 10분 동안 돌아오지 않으면 남은 참가자 중 무작위로 방장을 넘긴다. 남은 참가자가 없으면 방을 종료한다. 기존 방장 이양 없음·방장 부재 시 새 방 필수는 이 규칙으로 대체한다.
- 미정: 무작위 후보가 접속 중인 사람만인지, 다른 끊김 유예자도 포함하는지; 피고도 무작위 방장 후보에 포함(확정); 진행 중 재판에서 새 방장 권한·게임 역할 처리; 방장 명시적 나가기의 이양 시점/동작. 무작위 정책을 이 항목들에 확대 적용하지 않는다.
- 10분 계시의 기술 기준(끊김 감지 시각/마지막 확인 시각), 재접속과 만료의 정확한 경계/서버 지연 보정은 구현 설계가 필요하다. 감지 자체가 완벽하게 즉시 이루어진다는 보장은 없다. 나감 판정 뒤 복귀 시 재입장/역할/기존 기록·자격 처리도 기존 확정 범위를 넘겨 추정하지 않는다.

## 23차 방장과 게임 역할 분리
방장은 방 관리·게임 설정·시작을 담당한다. 게임 생성 뒤 참가자들이 역할을 선택하며 방장도 피고가 될 수 있다. 원고라는 별도 게임 역할·작성자와 원고의 연결을 만들지 않는다. 방장 무작위 이양 후보에는 피고도 포함하고 피고라는 이유로 제외하지 않는다. 24차: 후보는 접속자만, 명시적 나가기 즉시 무작위 이양. 후보 없고 복귀 유예자가 있으면 대기.
권한은 두 축으로 검사한다: 방장 여부로 설정/시작/방 관리, 해당 게임 역할로 피고의 수락·변론 및 피고 외 자격자의 투표. 방장이 피고이면 피고 기능과 방장 기능을 모두 가지되 투표는 불가하다. 방장 이양만으로 게임 역할·동결 투표 자격·과거 표를 바꾸지 않는 설계로 분리한다. 참가자 최소 수는 서로 다른 사람 3명이며 방장·피고 겸임을 두 명으로 세지 않는다.

## 25차 결과 공개 최종 정정
첫 라운드 동률은 유죄·무죄·기권 수와 1차 익명 이유를 먼저 보여준 뒤 피고 선택 최후 변론, 2차 투표로 이어진다. 최종 결과는 1·2차 익명 이유 모두 표시하며 전원 기권 무판결에서도 작성된 기권 이유를 보여준다. 진행 중인 라운드의 미완료 표·이유는 비공개지만 이미 종료된 1차 공개 결과를 2차가 진행 중이라는 이유로 다시 숨기지 않는다. 신원·이름은 계속 숨기며 추론 방지 보장은 하지 않는다. 방 종료로 중단된 게임의 미완료 표/이유 비공개 정책은 유지한다.
