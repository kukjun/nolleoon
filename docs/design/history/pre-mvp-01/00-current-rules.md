# 24~25차 일괄 결정: 최신 예외 처리 기준

근거: 2026-11-16 15:00:34 UTC 제안 1~7, 15:01:32 제안 8~11에 대한 15:11:41 사용자 답변. 1~4·6~11 승인, 5는 후속 25차 답변으로 1차 집계+익명 이유 선공개 및 최종 양 라운드·기권 이유 공개 확정. 이전 문서의 해당 미정/반대 규칙보다 이 문서를 우선한다. 구현·제품 시험은 아직 아니다.

1. 방장 명시적 나가기: 연결된 남은 참가자 중 즉시 무작위 이양. 아무도 남지 않으면 방 종료. 끊김은 10분 유예 후 이양.
2. 이양 후보는 현재 연결된 참가자만, 피고 포함. 연결자는 없으나 복귀 유예자가 남으면 방을 바로 닫지 않고 누군가 복귀하면 그중 방장을 정한다. 전원 10분 나감 처리되면 종료. 방장과 게임 역할은 독립이며 원고 역할을 추가하지 않는다.
3. 재판 시작 뒤 진행 중 입장자는 투표 불가지만 진행 상황·최종 결과를 볼 수 있고 자기 이력에 남는다. 종료 뒤 방 입장자는 이전 게임 결과를 못 본다. 서버 게임별 권한 검사 필요.
4. 표와 이유는 제출 확정 뒤 수정·철회 불가. 응답 유실 재시도는 같은 접수 확인이지 수정이 아니다.
5. 첫 동률이면 유죄·무죄·기권 수와 **1차 익명 이유**를 먼저 공개 → 피고 선택 최후 변론 → 같은 투표자·원래 기간으로 2차 투표. 최종 결과에서는 1·2차 익명 이유를 모두 공개한다. 전원 기권으로 무판결이어도 직접 적은 기권 이유를 공개한다. 작성자 이름·신원은 공개하지 않으며 익명 추론 가능성은 그대로 안내한다.
6. 방장이 방을 닫아 중단되면 참가자 개인 이력에는 ‘중단’과 사건 내용만 표시. 미완료 표·이유 비공개. 이전 완료 게임 기록은 그대로 유지.
7. 10분이 지나 나감 처리된 사람은 방이 열려 있으면 같은 링크로 새로 참가 가능. 이미 시작된 게임의 투표 자격은 되살리지 않고 3번 후발 참가자 규칙 적용.
8. 진행 중 피고가 나가면 그 판 중단. 투표자가 나가면 동결 투표자 수는 유지하고 마감까지 미제출이면 기권. 단순 끊김은 10분 복귀 유예이며 투표 deadline은 연장하지 않는다. 피고 퇴장 중단 시 기록 공개는 6번의 방 종료 중단과 같은 정책으로 자동 확장하지 않고 설계 검토에서 명시할 것.
9. 앱은 벌칙 내용 안내까지만, 실제 수행 완료 기록 없음. 방장이 투표 시간 1~10분을 1분 단위로 설정. 기본 3분, 새 게임마다 다시 3분 기본값.
10. 첫 버전 사건·벌칙·반론·이유는 텍스트만. 닉네임 중복 금지, 글자 수 제한은 화면 안내. 구체 길이·정규화 범위 등은 설계 초안으로 정한다. 대기 명단에서 제외된 사람도 링크로 재입장 가능, 영구 차단 아님.
11. 방장이 게임 설정 완료 전에 나가거나 끊겨도 방이 살아 있는 동안 입력된 설정을 보존하여 새 방장이 이어서 진행 가능. 단순 로컬 초안만으로 다른 새 방장에게 전달된다고 주장하지 말고 공유 초안 저장·버전·접수 UX를 설계한다.

## 남은 단계 경계
핵심 예외 정책은 일괄 정리되었다. 이유 공개 시점까지 확정되어 기술 선택·배포 조건·완료 기준으로 넘어간다. 글자 수, 닉네임 정규화, 서버 접속·10분/마감 경계, 초안 저장 방식·경합, 화면 상세는 설계자가 제안할 항목이다. 중단 원인별 기록 공개 정합성은 설계 시 보수적으로 검토하며 새로운 공개 권한을 임의 부여하지 않는다.

## 25차 결과 공개 최종 정정
첫 라운드 동률은 유죄·무죄·기권 수와 1차 익명 이유를 먼저 보여준 뒤 피고 선택 최후 변론, 2차 투표로 이어진다. 최종 결과는 1·2차 익명 이유 모두 표시하며 전원 기권 무판결에서도 작성된 기권 이유를 보여준다. 진행 중인 라운드의 미완료 표·이유는 비공개지만 이미 종료된 1차 공개 결과를 2차가 진행 중이라는 이유로 다시 숨기지 않는다. 신원·이름은 계속 숨기며 추론 방지 보장은 하지 않는다. 방 종료로 중단된 게임의 미완료 표/이유 비공개 정책은 유지한다.
