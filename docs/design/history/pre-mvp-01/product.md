# 제품 초안

> 23차 사용자 정정(이전 역할 가정 대체): 방장은 방 관리·게임 설정·시작 권한이며 게임 역할과 독립이다. 게임을 만든 뒤 역할을 선택하고 방장도 피고가 될 수 있다. 피고는 무작위 방장 이양 후보에서도 제외하지 않는다. 작성자=원고/방장≠피고 가정은 폐기하며 원고 역할은 정의되지 않았다.

상태: 계획 전. 아래 흐름은 논의를 위한 후보이며 구현 명세가 아니다.

## 목적

친구들이 여행 중 가볍게 즐길 수 있는 짧은 재판 게임.
앱을 작게 유지하면서 Codex 하네스의 구성과 검증을 직접 학습한다.

## 후보 흐름

방 입장 → 사건 접수 → 반론 → 익명 투표 → 결과 공개.
초기 사용 규모는 5명을 가정하되 고정 여부는 논의한다.

## 먼저 결정할 것

- 방 생성·입장 방식과 참가자 식별
- 피고인의 투표 참여 여부와 반론 횟수
- 투표 종료 조건, 동률, 기권, 연결 끊김 처리
- 중복·동시 투표, 새로고침 처리
- 익명성의 범위와 데이터 보존 기간
- 벌칙·촬영 동의와 중단 방식

## 범위 밖 후보

결제, 공개 커뮤니티, AI 심판, 자동 영상 게시, 대규모 운영.
실제 갈등 해결이나 법률 판단은 목표가 아니다.

## 기술

스택, 저장소, 배포 장소, 인증 방식 모두 미정.

## 2026-11-16 설계 진행 안내

위 내용은 최초 후보 초안으로 보존한다. 이후 대화에서 사건 작성자가 벌칙을 직접 미리 작성하는 방향을 확정했고, 모바일 요구사항·설계를 1~5단계로 진행하기로 했다.
최신 확정/제안/미결정 구분은 [제품 설계 문서](design/README.md), [MVP 범위](design/01-scope.md), [규칙 확정 질문](design/02-open-questions.md)을 따른다. 이 초기 초안의 익명 투표 등 후보를 확정 규칙으로 해석하지 않는다.

1차 규칙 답변 추가 반영: 모바일 웹·닉네임으로 사건 링크 참여, 피고 1명과 원고 포함 나머지의 투표, 이유 필수·종료 후 익명 공개, 피고의 시작 전 벌칙 확인/거절 및 시작 후 변경 금지. 이후 2차 답변으로 최소 3명·5명 초과 허용, 벌칙 거절 후 수정·재제안과 피고 수락, 작성자(방장)의 시작, 시작 시 투표자 고정 및 후발 입장자 투표 불가를 확정했다. 방장의 추가 관리 권한은 미정이며, 이름 없는 공개도 소수 인원에서 투표자 추론을 막지 못한다. 최신 세부 범위는 설계 문서를 따른다.

3차 답변 추가 반영: 투표 시간은 기본 약 3분·조절 가능, 연결 끊김 감지, 전원 투표 시 결과 자동 공개. 시간 조절 주체·시점·범위, 마감·0표·지연 표, 재접속·방장 수동 종료·반론·판결 정책은 아직 미정이다.

4차 답변으로 구체화: 기본 3분을 방장이 투표 전에 조절하며 시작 후 고정. 만료 시 미제출은 기권, 제출표로 판정하며 0표는 판결 없이 종료. 끊김을 표시하고 동일 참가자는 시간 내 재접속·투표 가능. 조기 종료는 두지 않는다. 반론·유죄 임계값·동률·시간 조절 범위·마감 경계의 기술적 처리 기준은 미정이다.

5차 답변: 직접 기권 가능. 직접 기권·만료 미제출 기권은 유죄/무죄 유효표에서 제외하며 유죄 1표·기권 3표는 유죄. 전원 직접 기권을 실질 유효표 0으로 보아 무판결 종료하는 해석은 확인 대기다. 일반 유죄 임계값·동률·반론 정책은 여전히 미정이다.

6차 답변으로 선택 반론·전원 직접 기권의 무판결 종료를 확정했다. 2~5단계 전체 초안은 [설계 문서 지도](design/README.md)에 있으며, 일반 유죄 임계값·동률·기권 이유/완료·반론 전환·복구/소유권·기술 선택 등은 제안 또는 미정이다. 앞선 차수의 문구는 당시 이력이며 최신 설계 확정표를 우선한다.

7차 결정: 첫 동률은 최후 변론 후 재투표, 두 번째 동률은 무죄. 기권 이유는 선택. 방장이 투표를 동시에 시작한다. 재투표의 시간/투표자/개시·최후 변론 세부는 미정이며 기존 3분이나 명단을 자동 재사용하지 않는다. 기능별 목업/실앱 경계는 [커버리지 감사](design/10-coverage-audit.md) 참조.

8차 결정: 첫 동률 뒤 피고 최후 변론은 선택, 방장이 같은 투표자·원래 설정 기간으로 재투표 개시. 재투표 전 1차 집계·익명 이유 공개(25차 정정)하고 익명 이유는 최종 판결 뒤 공개한다. 두 번째 동률 무죄·0유효표 무판결 재확인. 이전 차수의 미결정은 최신 결정으로 대체한다.

9차 확정: 로그인 없는 닉네임·역할 참여, 같은 기기·브라우저 링크 복귀 자동 복원 및 중복투표 방지. 다른 기기/브라우저는 닉네임만으로 동일인 아님. 방장도 동일 복원이며 미복귀 시 새 사건, MVP 이양 없음. 브라우저 데이터 삭제 시 복구 보장 안 함.

10차 비기능 확정: 현재 iPhone Safari·Android Chrome 우선/PC 가능, 본인과 타인에 연결 이상 표시 및 복귀 재동기화, 서버 마감·늦은 제출 실패 안내·참가자/라운드별 중복 방지. 감지 임계값 실측 결정, 중국 본토 접속은 배포 검증 전 미확인.

11차 확정: 초대 링크 접근, 서버 기록 저장 가능, 브라우저에서 자신이 참여한 게임의 개인 기록 조회. 이력 필드·완료 후 접근·보관 기간·삭제·이력 복구는 미정. 7일 삭제·텍스트 전용·개인정보 입력 안내는 미승인 제안으로 유지한다.

12차: 브라우저 개인 참여 이력에서 전체 결과·익명 이유 확인. 초기 자동 서버 삭제 기한 없음, 삭제 정책 추후 결정. 브라우저 데이터 삭제/기기 변경 시 이력 유실 가능. 완료 후 초대 링크 접근은 미정.

13차: 진행 중 링크 참여 가능, 첫 투표 뒤 신규 입장자는 재판 전체 투표 불가. 종료 후 기존 참가자만 결과·이유, 비참가자는 종료 안내. 이력은 이 브라우저 참여 게임만, 데이터 유실/새 브라우저 복원 불가. 최신 첫 투표 자격 고정 기준이 이전 재판 시작 표현보다 우선.

정정: 13차 기록의 첫 투표 시점 고정 단정은 철회. 이전 재판 시작 고정 동의와 이후 투표 시작 후 신규 투표 불가는 시점 변경 승인을 뜻하지 않으므로 Q-26으로 확인한다. 반론 중 신규 입장자의 자격은 미정이며 나머지 정책은 유지.

14차: 기권 제외 유죄/무죄 중 더 많은 쪽으로 판정. 직접 기권 완료 포함·시간 만료 미제출 기권. 동률 재투표/두 번째 무죄, 전원 기권 무판결 유지. 자격 고정 시점(Q-26)은 미정 유지.

15차 Q-26 확정: 방장 재판 시작 시 투표자 고정, 반론 중 신규 입장자는 해당 재판 투표 불가. 첫 투표/재투표는 같은 명단, 기존인 재접속 자격 유지. 관전 권한 추가 승인으로 해석하지 않음.

16차: 일반/최후 변론 피고 작성·건너뛰기, 완료 후 방장 투표 개시. 무응답이면 변론 없이 시작하며 피고에게 종료 안내. MVP 별도 변론 타이머 없음. 투표 조기 종료 금지는 유지.

## 17차 대기실 결정
시작 전 본인 역할 변경·피고 한 명·방장 권한과 게임 역할 분리, 방장의 끊김/이탈자 대기 명단 제거 및 시작 전 재입장, 피고 교체 시 벌칙 재수락 확정. 시작 뒤 역할·자격 고정. 제거는 영구 차단 아님. 문서만 변경, API/데이터/경합/시험은 구현 제안이며 미실행.

## 18차 시작 조건
접속 중인 서로 다른 참가자 최소 3명(방장·피고 포함, 두 역할 겸임 가능), 현 벌칙 수락 및 부족 조건 표시 확정. 벌칙 변경 시 수락 무효화·재수락. 끊김 인원은 최소 인원에서 제외하되 동결 자격 포함 여부는 미정으로 유지. 문서만 변경.

## 19차 자격 포함 기준
시작 시 서버 접속 판정으로 접속 중인 피고 외 자격자만 동결. 끊긴 추가 참가자는 복귀해도 투표 불가, 기존 관전 승인 범위 유지. 이미 동결 자격자가 이후 끊겼다 복귀하는 경우와 구분. presence 지연 한계와 서버 최종 검사 반영. 문서만 변경.

## 20차 같은 방의 연속 사건
같은 방에서 사건을 순차 진행하고 기존 참가자는 재입장하지 않는다. 사건마다 피고·벌칙 수락·자격 동결을 새로 정함. Room/RoomMember/CaseParticipant 분리와 사건별 API·이력 권한 설계를 제안. 다음 작성자/방장/링크/사건 참여 접근/방 수명은 미정. 기존 단일 사건 가정을 최신 설계 기준으로 대체하며 문서만 변경.

## 21차 최신 확정: 방 설정·접근·종료
- 흐름: 방 생성 → 방 안에서 게임 설정 → 플레이 → 같은 방에서 다음 게임 설정. 방 링크는 유지한다.
- 매 게임 설정은 방장만 한다. 방장이 시작하며 방장도 피고를 선택할 수 있고 참가자의 시작 전 본인 역할 선택/변경을 유지한다. 방장이 피고를 강제로 지정할 권한을 추가하지 않는다. 사건·피고·벌칙·시간을 게임별 설정으로 구성하는 UI 세부는 제안이며 시간 기본값 승계 등은 미정이다.
- 게임 1 종료 뒤 방에 들어온 사람은 게임 1 결과·이유를 볼 수 없고 게임 2에는 참여할 수 있다. 게임 1 참가자는 자기 기록에서 게임 1을 조회한다. 서버는 방 멤버십이 아닌 게임별 참여 권한을 검사한다. 24차: 진행 중 후발 참가자는 투표 불가·진행/최종 결과 조회·자기 이력 허용.
- 방장은 방을 종료할 수 있다. 종료 방에서는 신규 참가·신규 게임을 받지 않는다. 완료된 이전 게임은 해당 조회 자격자의 개인 기록에 남는다. 진행 중인 게임은 중단/판결 없음으로 처리한다. 24차: 방 종료 중단 이력은 중단·사건 내용만, 미완료 표·이유 비공개.
- 방장 복구는 같은 브라우저로 한다. 돌아올 수 없으면 새 방을 만든다. 이전 '새 사건' 안내를 방 모델에 맞춰 대체하며 MVP 이양은 추가하지 않는다. 자동 만료 시간은 미정이다.
- 기존 투표 조기 종료 금지는 정상 라운드 마감을 방장 임의로 당겨 판결하는 기능에 적용한다. 방 종료는 별도 명시적 예외로 진행 게임을 **중단·무판결** 처리하며 제출된 표로 승패를 계산하지 않는다.

## 22차 나가기·복구·방장 이양 확정
- 명시적 나가기는 즉시 나감으로 처리한다. 연결이 끊긴 사람은 10분 안에 돌아오지 않으면 나간 것으로 처리한다. 10분 안 같은 브라우저로 복귀하면 기존 참가 신원을 복원한다. 연결 끊김을 즉시 나감으로 처리하지 않는다.
- 모두 나가면 방이 종료된다. 방장의 명시적 방 종료 기능도 유지한다. 투표 마감은 별도로 진행하며 연결 복구 유예 10분이 투표 시간을 연장하지 않는다. 동결 투표 자격과 접속/나감 상태를 혼동하지 않는다.
- 방장이 끊긴 뒤 10분 동안 돌아오지 않으면 남은 참가자 중 무작위로 방장을 넘긴다. 남은 참가자가 없으면 방을 종료한다. 기존 방장 이양 없음·방장 부재 시 새 방 필수는 이 규칙으로 대체한다.
- 미정: 무작위 후보가 접속 중인 사람만인지, 다른 끊김 유예자도 포함하는지; 피고도 무작위 방장 후보에 포함(확정); 진행 중 재판에서 새 방장 권한·게임 역할 처리; 방장 명시적 나가기의 이양 시점/동작. 무작위 정책을 이 항목들에 확대 적용하지 않는다.
- 10분 계시의 기술 기준(끊김 감지 시각/마지막 확인 시각), 재접속과 만료의 정확한 경계/서버 지연 보정은 구현 설계가 필요하다. 감지 자체가 완벽하게 즉시 이루어진다는 보장은 없다. 나감 판정 뒤 복귀 시 재입장/역할/기존 기록·자격 처리도 기존 확정 범위를 넘겨 추정하지 않는다.

## 23차 방장과 게임 역할 분리
방장은 방 관리·게임 설정·시작을 담당한다. 게임 생성 뒤 참가자들이 역할을 선택하며 방장도 피고가 될 수 있다. 원고라는 별도 게임 역할·작성자와 원고의 연결을 만들지 않는다. 방장 무작위 이양 후보에는 피고도 포함하고 피고라는 이유로 제외하지 않는다. 24차: 후보는 접속자만, 명시적 나가기 즉시 무작위 이양. 후보 없고 복귀 유예자가 있으면 대기.
권한은 두 축으로 검사한다: 방장 여부로 설정/시작/방 관리, 해당 게임 역할로 피고의 수락·변론 및 피고 외 자격자의 투표. 방장이 피고이면 피고 기능과 방장 기능을 모두 가지되 투표는 불가하다. 방장 이양만으로 게임 역할·동결 투표 자격·과거 표를 바꾸지 않는 설계로 분리한다. 참가자 최소 수는 서로 다른 사람 3명이며 방장·피고 겸임을 두 명으로 세지 않는다.

## 24차 일괄 승인
1~4·6~11의 정확한 제안/사용자 답변을 대화에서 확인해 docs/design/00-current-rules.md에 기록. 5번 수정의 이유 공개 시점은 질문 대기, 기존 집계만 선공개 규칙 유지. 문서만 변경, 제품 시험 미실행.

## 25차 결과 공개 최종 정정
첫 라운드 동률은 유죄·무죄·기권 수와 1차 익명 이유를 먼저 보여준 뒤 피고 선택 최후 변론, 2차 투표로 이어진다. 최종 결과는 1·2차 익명 이유 모두 표시하며 전원 기권 무판결에서도 작성된 기권 이유를 보여준다. 진행 중인 라운드의 미완료 표·이유는 비공개지만 이미 종료된 1차 공개 결과를 2차가 진행 중이라는 이유로 다시 숨기지 않는다. 신원·이름은 계속 숨기며 추론 방지 보장은 하지 않는다. 방 종료로 중단된 게임의 미완료 표/이유 비공개 정책은 유지한다.
