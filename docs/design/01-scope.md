# MVP 범위

[현재 규칙](00-current-rules.md)을 만족하는 모바일 다인 게임 한 판과 같은 방의 다음 판까지 구현한다.

포함: 방 생성/초대/참여, 역할·벌칙 수락, 호스트 설정/시작, 선택 변론, 동시 투표/기권, 동률 재투표, 익명 이유, 재접속/10분 나감/무작위 방장 이양, 방 종료, 게임별 권한·브라우저 기록, 공유 초안, 모바일 디자인 시스템.

제외: 계정/다른 기기 신원 복원, 원고 역할, 실시간 채팅·첨부, 벌칙 수행 추적, 공개 방 검색, 결제, 무기한 보관 보장, 중국 현지 접속 검증. 실제 서비스 비밀값/권한/배포는 별도 실행 경계를 지킨다.

개발은 티켓 순서의 작은 기능 단위 TDD, 통합 검증, 다중 브라우저 E2E, 독립 리뷰, 외부 접속 확인 순서다. 하네스 자체 시험이나 단일 브라우저 목업은 제품 합격이 아니다.
