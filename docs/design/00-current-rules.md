# 현재 제품 규칙 · MVP 기준선

2026-11-16 사용자 최종 결정 기준. 이전 대화 차수별 기록은 [이력](history/pre-mvp-01/README-history.md)이며 구현 규칙이 아니다. 이 문서가 정책 원본이고 요구/시나리오/시험 표는 추적용이다. 제품 구현·제품 시험 완료를 뜻하지 않는다.

## 방과 역할
- 로그인 없이 닉네임으로 방 링크에 참여한다. 방 생성 → 방장 게임 설정 → 본인 역할 선택 → 플레이 → 같은 방 다음 게임이다. 방 링크와 참가 신원은 유지한다.
- 방장만 게임 내용·벌칙·시간 설정, 재판 시작·투표 시작·방 종료를 한다. 방장도 피고 가능하며 방 관리 권한과 게임 역할은 독립이다. 원고 역할은 없다. 피고는 최대 한 명이고 투표하지 않는다.
- 시작 전 본인 역할 변경 가능. 방장은 끊김/이탈자 대기 명단을 제거할 수 있으나 영구 차단은 아니다. 시작 전 재입장 가능. 다른 사람 역할 강제 지정은 없다.
- 접속 중인 서로 다른 사람 최소 3명(방장·피고 포함, 겸임 가능), 현 피고가 최신 벌칙을 수락해야 재판 시작 가능. 5명 상한은 없다. 벌칙 수정/피고 교체는 수락을 무효화한다.
- 재판 시작 시 역할·벌칙과 접속 중인 피고 외 투표자 집합을 고정한다. 이후 끊김/나감에도 집합은 줄이지 않는다. 시작 당시 끊겼거나 늦게 들어온 사람은 그 게임 1·2차 투표 불가다.
- 설정 중 서버에 저장된 초안은 방이 존속하면 새 방장이 이어 쓴다. 다음 게임은 피고·수락·자격·표를 새로 정하고 시간 기본값은 3분이다.

## 변론·투표·결과
- 일반 변론·최후 변론은 선택이다. 피고가 작성/건너뛰기 후 방장이 투표를 시작하며 무응답이어도 진행 가능하고 피고에게 변론 종료를 알린다. 변론 타이머는 없다.
- 투표는 모두 동시에 시작하며 서버가 단일 마감을 관리한다. 기본 3분, 방장이 투표 시작 전 1~10분 정수 분 단위로 조절하고 시작 후 고정한다. 2차는 1차의 투표자 집합과 설정 기간을 사용한다.
- 유죄·무죄 이유는 필수, 기권 이유는 선택. 제출한 표·이유는 수정/철회 불가. 동일 요청 재시도는 접수 확인이며 추가 표를 만들지 않는다.
- 직접 기권도 완료다. 전원 제출 즉시 자동 정산, 시간 만료 미제출은 기권. 수동 조기 판결은 없다. 늦은 제출은 실패 안내한다.
- G>N 유죄, N>G 무죄. 기권은 유효표에서 제외한다. G+N=0이면 무판결이다. 1차 G=N>0이면 1차 집계·익명 이유 공개 → 선택 최후 변론 → 방장 2차 투표 개시. 2차 G=N>0은 무죄다.
- 현재 진행 라운드의 타인 표·이유는 비공개다. 1차에 공개한 이유는 최후 변론/2차에서도 유지한다. 최종 결과는 양 라운드 이유를 구분해 공개하고 무판결에도 작성된 기권 이유를 표시한다. 이름/신원은 숨기되 표현·소수 인원으로 추론될 가능성을 안내한다.
- 벌칙은 유죄 결과에 안내만 한다. 수행 확인 기능은 없다.

## 연결·퇴장·이양
- 동일 브라우저의 유효 신원으로 복귀하면 접수 상태를 동기화한다. 다른 브라우저/데이터 삭제/같은 닉네임은 복구 수단이 아니다. 방장 복귀가 이미 이양된 권한을 되찾게 하지 않는다.
- 단절은 즉시 퇴장이 아니다. 끊김 후 10분 내 복귀는 기존 멤버십, 10분 미복귀는 나감이다. 명시적 나가기는 즉시 처리한다. 감지 임계값은 실측하며 투표 마감은 연장하지 않는다.
- 방장 나가기 또는 10분 미복귀 시 접속 중인 남은 참가자에게 무작위 이양한다. 피고도 후보다. 후보가 없고 복귀 유예자가 있으면 대기하다 복귀 시 지정한다. 전원 나감 확정이면 방 종료다.
- 피고 나감은 게임 중단, 투표자 나감은 동결 수 유지·마감 때 미제출 기권이다. 10분 뒤 재입장은 새 멤버십이며 이전 게임 투표권은 부활하지 않는다.

## 접근·기록·입력
- 진행 중 후발 참가자는 관전·최종 결과·개인 이력 조회 가능하나 투표 불가. 게임 종료 후 들어온 사람은 그 게임 기록을 볼 수 없다. 방 멤버십만으로 과거 게임을 공개하지 않는다.
- 자기 브라우저로 참여한 게임의 결과·익명 이유를 기록에서 본다. 서버 기록은 초기 자동 삭제 기한이 없지만 영구 보관을 보장하지 않는다. 데이터 삭제/다른 브라우저에서 이력 복구는 없다.
- 방장 방 종료는 신규 입장/게임을 막고 진행 게임을 중단·무판결 처리한다. 방 종료 중단 이력은 사건 내용+중단만, 미완료 표·이유는 비공개다. 이전 완료 게임 기록은 유지한다.
- 피고 퇴장에 따른 중단 이력 공개 범위(이미 공개한 1차 이유 포함)는 [결정 대기 #33](https://github.com/kukjun/trip-court/issues/33). 미정 범위를 공개 승인으로 해석하지 않는다.
- 사건·벌칙·변론·이유는 텍스트 전용. 닉네임 중복 금지와 입력 길이 안내. 길이·정규화 값은 구현 설계이며 별도 확인한다.

## 기술·지원·완료 경계
- React + TypeScript, NestJS 내부 통합 BFF, 클린 아키텍처, SQLite. DB용 Docker는 필요 없다. 세부 선택은 [ADR](../decisions/0002-mvp-architecture.md).
- Mac mini에서 기존 Cloudflare Tunnel 방식으로 외부 도메인에 연결한다. 기존 서비스 설정/포트/데이터를 재사용하거나 변경하지 않는다. 외부 인터넷 접속 확인이 배포 합격 범위이며 중국 현지 검증은 MVP 제외다.
- iPhone Safari·Android Chrome 우선, PC 가능. 시험 당시 버전을 기록하며 인앱 브라우저는 자동 포함하지 않는다. 실제 모바일 시험 없이 실기기 합격을 주장하지 않는다.
