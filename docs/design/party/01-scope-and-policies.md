# 파티게임 확장: 확정 규칙과 실행 기본값

관련: #75, #76, #74. 사용자는 디자인 방향을 승인하고 확장 구현·검증을 위임했다. 아래 **사용자 확정**과 **위임 범위의 구현 기본값**, **미결정**은 서로 다르다.

## 사용자 확정
- 하나의 방에서 팀 나누기, 제비 뽑기, 재판을 선택한다. 눈치게임은 범위 밖이다.
- 팀은 균형 배정하며 벌칙이나 승패가 없다.
- 제비는 각자 미리 배정된 **자기 제비 한 장**을 본인이 뒤집는다. 여러 장 중 고르는 화면은 폐기한다. 당첨자가 벌칙 대상이다.
- 아바타 약 10종과 사용자 사진 선택, 방·게임·결과에 같은 사람으로 표시한다.
- 사람 중심 로비와 현재 행동에 집중하는 화면을 사용한다. 이전 단계의 폼을 계속 쌓지 않지만 내용 다시 보기는 제공한다.
- 재판의 기존 규칙은 유지한다. 방장과 피고 역할은 독립이다. 첫 동률은 1차 결과·익명 이유 → 최후 변론 → 재투표, 두 번째 동률은 무죄다.
- 모든 작업은 테스트·PR·독립 리뷰를 거치며 기존 데이터와 미완성 초안을 보존한다.

## 위임 범위의 구현 기본값
이 값은 사용자의 직접 인용이 아니다. 검증 가능한 작은 구현을 위해 선택했으며 변경할 때 영향과 테스트를 갱신한다.

| 항목 | 기본값 | 근거 / 반례 |
|---|---|---|
| 새 게임 대상 | 시작 시 연결된 방 참가자를 고정, 이후 참가자는 관전 | 늦은 입장으로 당첨 수·팀 구성 변경 금지 |
| 팀 나누기 | 최소 2명, 팀 수 2~대상 인원, 인원 차 최대 1 | 1인 팀 분할·빈 팀·한 사람 중복 배정 거절 |
| 제비 | 최소 2명, 당첨 N은 1~대상 인원 | 0명/대상 초과 거절; 전원 당첨 선택은 가능하며 UI에서 명확히 알림 |
| 공개 | 실제 게임 대상에게 이미 뒤집힌 결과 표시, 미공개 결과는 본인에게도 전송하지 않음 | 새로고침/실패 재시도는 같은 결과; 늦은 관전자는 과거/비공개 결과에 접근하지 않음 |
| 제비 벌칙 확인 | 시작 전 대상·N·벌칙 전문을 표시, 시작 후 고정 | 재판의 피고 동의를 제비에 그대로 복사하거나 새 필수 준비 토글을 만들지 않음 |
| 방장 | 게임 선택·설정·시작·다음 판 권한, 게임 역할과 별개 | 비방장 직접 API 호출 거절 |
| 아바타 | 현재 브라우저 프로필을 현재 방/결과에 표시, 역사적 초상 스냅샷 아님 | 쿠키 손실은 사진/닉네임으로 복구하지 않음 |
| 사진 | JPEG/PNG/WebP, 입력 1 MiB·4 MP, 서버 정규화 후 256px·64 KiB 이하, 현재 썸네일 1개 | SVG/GIF/URL·위장·압축 폭탄 거절; 원본/EXIF 보관 안 함 |
| 사진 교체 | 프리셋 복귀 시 활성 썸네일 제거, 백업에 남을 수 있음을 안내 | 백업을 임의로 영구 삭제하지 않음; 만료 세션의 물리 정리 정책은 별도 운영 결정 |

고정 N명과 순차 공개로 남은 당첨 여부를 추론할 수 있다. 서버가 미공개 결과를 숨기는 것과 완전한 추론 방지는 다르다.

## 미결정 / 영향 범위만 차단
- **#101:** 제비 미공개자가 장기 이탈하거나 방이 닫혔을 때의 종료·벌칙·기록 공개 정책. 자동 뒤집기, 재추첨, 당첨 재배정은 하지 않는다. 미공개 결과를 보존하고 미완료 상태로 표시한다. 해당 전이의 최종 인수는 결정 전 차단한다.
- **#33:** 재판 피고 퇴장 중단 기록 공개 범위. 기존 보수적 비공개를 유지한다.
- **#36/#63:** 원격 CI 인증 범위와 실기기 접근은 로컬 통과로 대체하지 않는다.

## 상태와 권한
| 유형 | 상태 흐름 | 누가 동작하는가 |
|---|---|---|
| 공통 방 | 입장 → 로비 → 게임 설정 → 진행 → 결과 → 같은 방 다음 게임 | 방장 설정/시작, 개인은 자기 행동 |
| 팀 | 설정 → 참가자 고정/배정 저장 → 결과 | 방장 시작, 결과 조회는 허용된 참가자 |
| 제비 | 설정 → 배정 저장/미공개 → 개인 공개 반복 → 전원 공개 결과 | 각자 자기 제비만 공개, 서버가 결과/버전 보장 |
| 재판 | 준비 → 변론 → 1차 투표 → 결과 또는 최후 변론 → 2차 투표 → 결과 | 기존 피고/투표권/방장 권한 유지 |

3분 제한은 재판 투표의 설정이며 팀/제비에 자동 적용하지 않는다. 방의 10분 재접속 유예와 모두 이탈 시 닫힘은 공통 수명 규칙이나 게임별 결과 공개를 대신 결정하지 않는다. 방장 이탈 확정 후 유효한 후보에게 랜덤 위임하며 잠깐 연결 끊김만으로 중복 위임하지 않는다.

## 검토 반례
1. 제비를 두 번 눌러 다른 결과를 받음 → 금지, 멱등 응답.
2. 결과를 숨긴 CSS 뒤에 미공개 당첨 데이터가 있음 → 금지, API에서도 제외.
3. 방장이 피고가 될 수 없음 → 기존 사용자 규칙 위반.
4. 팀 결과에 벌칙이 보임 → 사용자 확정 위반.
5. 뒤늦게 들어온 사람이 과거 게임 사진/결과를 조회함 → 참여 권한 확인.
6. 로컬 테스트 통과를 원격 CI/실기기/운영 이전 완료로 표기함 → 증거 위반.
7. 새 마이그레이션을 되돌리려고 운영 DB를 재생성함 → 금지, 별도 복구 리허설과 승인된 전환.
