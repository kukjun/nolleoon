# 여행방 개편 규칙과 수용 추적

현재 사용자 노출 브랜드는 **놀러온**이다. [브랜드·운영 구분](../branding.md)에서 주소와 호환 경계를 확인한다.

상태: 승인된 제품 방향 + 구현 검증 진행 중. 이 문서는 기존 일회성 방 규칙을 과거 데이터에 소급 적용하지 않는다. 상위 [#117](https://github.com/kukjun/nolleoon/issues/117), [정책 검토](travel-policy-review.md).

## 확정한 규칙

1. React 웹 우선. Flutter 앱/스토어 배포는 제외한다. React/Nest/SQLite를 유지한다.
2. 카카오 로그인 후 방 입장·게임 가능. 로그인 전에는 초대 최소 안내만 제공하고 로그인 후 같은 초대로 복귀한다. 프로필/친구 목록 등 불필요한 카카오 권한을 수집하지 않는다.
3. 여행 날짜는 선택. 영속 여행방은 모든 사람이 오프라인이어도 남는다. 관리자가 여행 종료하면 읽기 전용, 재활성화 가능하다. 현재 연결 상태와 소속은 다르다.
4. 방 생성자가 관리자. 설정·참가자 관리·종료를 담당하고 직접 다른 현재 멤버에게 넘길 수 있다. 오프라인으로 자동 이양하지 않으며, 퇴장/계정삭제 전 이양한다.
5. 유효한 초대 링크와 로그인으로 별도 승인 없이 가입한다. 관리자는 초대를 폐기/재발급하고 멤버를 내보낼 수 있다.
6. 현재 멤버 누구나 판을 만들고 시작한다. 판 생성자가 진행자이며 방 관리자와 독립이다. 진행자의 최종 이탈은 판의 가능한 남은 참가자에게 무작위 위임한다. 관리자/진행자가 피고가 되는 것을 금지하지 않는다.
7. 게임별 참가자는 선택하고 시작 시 고정한다. 같은 여행방의 진행 판은 한 개다. 뒤늦게 가입한 사람을 현재 판 참가자로 자동 편입하지 않는다.
8. 일반 결과는 현재 여행방 멤버에게 공개한다. 재판 사건·투표 이유·결과는 현재 멤버이면서 그 판 참가자인 사람만 본다. 관리권은 상세 열람권이 아니다. 방을 나가면 방/기록 접근을 잃는다.
9. 기존 팀 나누기는 균형 배정·벌칙 없음, 제비는 각자 배정된 자기 제비만 뒤집고 뽑힌 사람이 벌칙, 재판은 기존 규칙을 유지한다. 메뉴 정하기를 네 번째 게임으로 추가한다. 미션·어워즈는 범위 밖이다.
10. 미공개 제비 참가자가 연결 끊긴 후 10분 내 돌아오지 않으면 판을 미완료 종료한다. 이미 공개된 결과만 남기고 자동 공개/당첨자 재배정하지 않는다. 새 판은 새 배정이다. 이 timeout은 여행방 탈퇴가 아니다.
11. 과거 기록은 로그인 후 명시적으로 선택한 것만 연결한다. 유효한 기존 브라우저 세션이 증명한 본인 기록만 가능하며 닉네임/초대링크/localStorage 목록은 증명이 아니다. 닫힌 방을 새 여행방으로 재생성하지 않는다.
12. 방 삭제는 관리자만 경고/확인을 거쳐 가능하도록 설계한다. 계정 탈퇴 시 개인 프로필·로그인 연결 정리 방향은 승인됐지만 공동 기록·자유 텍스트·백업 처리 상세는 아직 결정 게이트다. 이 문서는 운영 영구삭제의 실행 승인이 아니다.

## 권한 모델

Account → TravelMembership → GameParticipant를 구분한다. 현재 멤버 검사와 당시 참가자 검사를 모두 한다. 동일 계정의 다른 기기는 같은 멤버/표로 취급한다. #119 결정 전 임시 보호로, 다시 가입한 새 membership에 이전 재판 권한을 자동 연결하지 않는다. 이는 재가입 후 권한 복구의 최종 정책 확정이 아니다. 비참가 진행자는 단계 제어와 민감 상세 열람을 구분하고 투표/변론을 대신하지 않는다.

## 상태 전이와 반례

| 대상 | 이전 → 이후 | 허용 조건 | 반드시 거부/보류 |
|---|---|---|---|
| 여행방 | 없음 → open | 로그인 계정 생성 | 비로그인 생성 |
| 여행방 | open → closed | 현재 관리자, 진행 판 없음 | 비관리자 또는 active 판 중 종료는 gate |
| 여행방 | closed → open | 현재 관리자 | 비관리자 재활성화 |
| 소속 | current → current | offline/재시작/10분 경과 | presence로 소속 삭제 금지 |
| 소속 | current → left/removed | 승인된 나가기/추방, 관리자 이양 선행 | 마지막 관리자/활성 판 예외 gate |
| 판 | 없음 → draft | 현재 멤버, open 방, 다른 draft/active 없음 | 종료 방/동시 두 판 |
| 판 | draft → active/terminal | 진행자, 게임별 준비 조건, 선택 명단 동결 | late join 참가 편입 |
| 제비 | active → incomplete | 미공개 참가자 단절 10분 경과 | 자동 뒤집기/당첨 재배정 |

문서의 여행방 활성/종료는 저장 상태 `open/closed`를 뜻하며 게임의 `draft/active/completed/incomplete/interrupted`와 다르다. 공개 권한 반례는 [기계 판독 사례](travel-access-cases.json), 문서 무결성 시험은 `tests/docs/travel-policy.test.mjs`에 고정한다. 이는 실제 HTTP 권한 시험을 대체하지 않는다.
