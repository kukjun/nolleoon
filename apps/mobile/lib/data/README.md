# Native data boundary (#159)

This directory has no UI or credential persistence. `wire_models.dart` decodes the pinned synthetic fixtures under `contracts/flutter/` with exact object keys, native integer/enum types and immutable nested data. Nullable/restricted/redacted game projections are distinct. `NativeSessionDto` separately requires native `expiresAt`; the browser fixture `SessionDto` is not a native login response.

`ApiClient` requires an injected transport, route resolver and asynchronous bearer reader. `NativeRoutes` uses the `/api/native/*` paths confirmed with the #162 implementer; this does **not** prove deployed native endpoints/authentication. Production host is fixed HTTPS `nolleoon.kukjun.com`; tests inject transport and make no external calls. No API accepts arbitrary caller URLs, Cookie, Origin or browser CSRF impersonation. `IoApiTransport` uses standard Dart HttpClient, refuses redirects, caps response bytes and closes/aborts on cancellation. It has no token storage or logging. Credential acquisition, secure storage, expiration handling and token clearing are the auth owner's responsibility.

Call `read(operation, decoder, parameters:, cursor:, cancel:)` for GETs. Create a `MutationIntent` once for a user action, with its requestId and version, then pass that same object to `mutate` if the outcome is uncertain. Serialized bytes remain immutable. No automatic retry happens. Concurrent use is blocked. Invitation issuance and auth exchange cannot be replayed with the same intent; invite duplicates do not return the old token and automatically creating another invitation would revoke its predecessor. Refresh and explicitly initiate a new action instead. Never infer rollback from cancel/timeout.

Failures distinguish network, timeout, cancelled, invalidResponse, server, missing local authentication, and retryNotAllowed. Server messages/bodies/headers are not copied into exceptions or printed. A server 401 remains a server failure with code/status for the auth layer to handle; client timeouts do not become fake HTTP statuses.

Only synthetic Flutter tests have run. No live Kakao/native API login, device networking, secure-storage behavior, iOS/Android build, or deployment is claimed by this package. The scaffold shell is unchanged. No new dependency is required.
